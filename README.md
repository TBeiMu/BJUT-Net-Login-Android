# 工小助

北京工业大学 Android 校园助手。整学期课表、校园网登录和资费查询集中在一个 App 中。

## 三页功能

| 页面 | 功能 |
| --- | --- |
| 课表 | 一次学校登录导入研究生整个学期，离线查看；默认“今日”时间线，可切换整周网格、上下切周、查看课程详情与重叠课程；离线添加自定义课程，编辑和删除本次或指定周次 |
| 资费 | 已用流量、可用流量、消费保护、账户余额、在线设备及单台设备注销 |
| 我的 | 课表管理、校园网账号、校园网连接、外观设置、检查更新、关于工小助 |

课表是默认首页，默认显示“今日”：今天的课按时间排成时间线，正在上的课显示进度与剩余时间，课间显示空闲时长，末尾预告明天的课；上方七天条可点选或左右滑动切换日期。右下角“整周”切换到整周网格，选择会被记住。

v0.5.1 固定了“今日／整周”切换按钮的位置，以及左上角小字和标题区的占位；校园网提示与周次切换时不再推动周围布局，并修复“我的 → 检查更新”结束后箭头漂移。详见 [课表布局验证](docs/testing/课表布局稳定性验证.md)与[更新箭头验证](docs/testing/检查更新箭头稳定性验证.md)。

整周网格每页展示 12 节及北工大上课时间，并以“此刻线”标出当前时间，向上划下一周、向下划上一周；课程跟随手指移动，日期同步过渡，星期和左侧时间栏固定；慢拖超过课程区域的 25% 或快速划动翻一周，短拖回弹，首末周不循环。保留 v0.4.12 的连续轻划与松手后周次即时反馈。右侧圆点可展开周次列表，“回到本周”位于圆点下方，从右侧滑入，使用模糊半透明底色。支持自定义壁纸、深色模式和字体放大。

## 开始使用

### 导入课表

1. 连接可上网的 WiFi 或开启移动数据，点击课表右上角“＋”，选择“导入研究生课表”。
2. 在学校统一身份认证页面输入学号、密码及需要的验证码，完成一次登录。
3. App 自动获取当前整个学期，无需逐周操作。提交学校登录后，切换 App 或锁屏仍可继续导入，完成后可离线查看。

课表绑定独立学号，不跟随校园网默认账号切换。统一认证密码不会保存。后台导入显示静默进度通知，可点按返回课表或暂停；完成后通知自动移除。网络断开或切换、手动暂停、从最近任务划掉 App 或系统停止任务后保留进度，返回后手动继续并重新登录，也可取消本次导入。刷新全部完成前保留旧课表。

v0.5.1 支持后台继续导入，v0.5.0 及以前仍需保持前台。详见 [后台导入验证记录](docs/testing/课表后台导入验证.md)。尚未提交的学校登录表单在切后台后仍会关闭，需要返回 App 登录；单次导入最长运行 30 分钟，不自动重试。

课表右上角“＋”先选择研究生课表导入或添加自定义课程，本科生导入暂未开放。自定义课程可离线按星期、周次和节次安排，首次先设置本地学期；学校及自定义课程均可在详情中编辑、删除本次或指定周次。完整刷新后学校课程以新数据为准，自定义课程保留；旧本地学期可在“我的 → 课表管理”查看。详见 [课程添加与编辑验证](docs/testing/课程添加与编辑验证.md)。

后续源码新增自定义课程星期多选，并将详情简化为课程卡片，编辑、删除和右侧关闭同排；尚未发布对应 APK，见 [本次验证](docs/testing/星期多选与详情布局验证.md)。

### 登录校园网

1. 在“我的 → 校园网账号”添加账号密码；首个账号自动设为默认，之后可在账号卡片中点击“设为默认”切换。
2. 连接校园公共 WiFi 或宿舍 WiFi，打开 App 即可尝试自动登录；也可在“校园网连接”手动登录。
3. 认证开始后可以切换应用或锁屏，本次短时任务会继续；手动取消、划掉 App 或 WiFi 切换时停止。

v0.5.2 支持姓名补全：首次添加账号时备注留空，优先使用本机相同学号的课表姓名；否则在前台 WiFi 可用后，用本账号尝试一次学校登录获取姓名并加密保存为备注。姓名未取得或需要验证码时，账号仍可正常使用，之后导入课表可补全；已填写的自定义备注会保留。详见 [姓名补全验证](docs/testing/账号姓名补全验证.md)。

确认无实体 WiFi 时，课表左上角显示“未连接WiFi”约 1 秒后恢复周次，不启动认证。认证开始后显示“正在登录校园网”，超过 3.5 秒仍未完成时显示“登录超时”约 1 秒后恢复周次，认证继续执行。确认成功立即替换为“校园网已连接”约 2 秒，并取消后续超时提示。实际进度和错误在“我的 → 校园网连接”查看；已联网不会自动退出，修改默认账号用于后续登录。

### 查询资费与在线设备

进入“资费”，使用所选校园网账号登录学校自助服务。首次进入可自动查询，也可点击“登录查询”或“刷新资费”；学校要求验证码时自行填写。自动查询登录未完成时，可选择内置网页登录，预填密码但由用户点击登录。

四张卡片及设备信息均来自学校返回数据，缺失显示“—”或“未获取”。设备显示登录时间、在线时长和使用流量。注销前需选定一台设备并确认；注销本机会中断联网，可在校园网连接页手动恢复。

### 更新与外观

“我的 → 检查更新”直接检查新版：有新版弹窗，最新时提示“已是最新，无需更新”。弹窗按钮为“取消更新／忽略本次更新／立即更新”。下载需要用户操作，移动数据下载还需本次同意；后台下载遇到断网或换网后暂停，返回手动继续。安装由系统确认。

从 v0.4.8 及以前升级的迁移说明见“下载与安装”。“我的 → 外观设置”提供三种背景：

- 颜色背景：蓝青、薄荷、薰衣草、樱粉、暖杏、灰白，以同色系的淡雅纸色作底，点击色卡选择。
- 跟随壁纸颜色：根据手机桌面壁纸主色生成柔和背景，随壁纸变化更新；不读取或展示系统壁纸原图。
- 自选壁纸：使用系统照片选择器导入图片，模糊强度可调 0–24，新图默认为 12；升级后原有图片保持清晰。

所有模式均有预览。切换模式或恢复默认会保留已选图片与模糊值；背景不改变按钮、导航及课程配色。外观配置仅在本机保存，不申请整个相册或广泛存储权限。部分动态壁纸暂未提供颜色时，保留本次已有颜色或使用蓝青背景。

## 网络与本机资料

| 功能 | 网络规则 |
| --- | --- |
| 校园网认证、资费查询 | 只使用当前实体 WiFi，不转用移动数据 |
| 学校课表 | 优先可上网的 WiFi，也可使用移动数据；换网后暂停 |
| 更新检查 | 可用 WiFi 或移动数据 |
| APK 下载 | 移动数据需单次同意，换网后暂停并手动继续 |

校园网账号和课表分别使用 Android Keystore／AES-GCM 加密保存在本机，不做云端同步，排除系统备份。学校网页登录的 Cookie、验证码和密码仅在临时会话中使用。卸载或清除应用数据会删除本机资料；文件损坏时明确提示，不静默覆盖。

校园认证协议包含 HTTP 请求，本机加密不代表认证传输已加密。学校课表与资费通过 HTTPS 访问，保留证书校验。当前不提供后台常驻、定时保活、IPv6 认证、自动连接 WiFi、本科课表、成绩或考试功能。

## 常见问题

- **课表导入暂停了？** v0.5.1 支持切后台继续导入；换网、断网、主动暂停或任务被系统停止后，需要返回前台手动继续并重新完成学校登录。已有完整课表仍可离线查看。
- **提示超时，但稍后能够上网？** 课表标题只是短暂提示，认证任务仍可能执行；到校园网连接页查看实际结果。
- **资费页面需要额外登录？** 校园网接入和资费网站是两个独立会话。按提示填写验证码或使用内置网页登录。
- **改名后无法检查更新？** v0.4.8 及以前的旧地址被校验拦截，手动覆盖安装 v0.4.9 一次即可；之后可在 App 内检查更新。

反馈问题可提交 [Issue](https://github.com/TBeiMu/BJUT_gxz/issues)，说明版本、手机型号、Android 版本、网络类型及脱敏截图；请勿提交密码、Cookie、访问令牌或原始登录态页面。

## 开发与文档

使用 Kotlin、Jetpack Compose、协程和 Gradle Wrapper。开发环境为 JDK 21、Android SDK Platform 36、Build Tools 36.0.0；SDK 路径写在被忽略的 `local.properties` 中。

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:testReleaseUnitTest :app:lintDebug :app:lintRelease :app:assembleDebug
```

Linux／macOS 使用 `./gradlew`。设备测试只在独立测试模拟器中运行，使用虚构资料；不要在保存真实账号的手机上执行清数据测试。
