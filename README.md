北京工业大学校园网 Android 登录助手。连接校园 WiFi 后打开 App，使用已保存的默认账号登录，减少反复输入账号密码。

**支持 Android 12 及以上 · 线上正式版 v0.3.2 · 待发布 v0.3.3**

## 下载与安装

[下载正式版 APK](https://github.com/TBeiMu/BJUT-Net-Login-Android/releases/latest/download/gongxiaozhu.apk) · [所有版本与更新说明](https://github.com/TBeiMu/BJUT-Net-Login-Android/releases) · [SHA-256 校验文件](https://github.com/TBeiMu/BJUT-Net-Login-Android/releases/latest/download/SHA256SUMS.txt)

下载 `gongxiaozhu.apk` 后，在手机上允许下载应用的浏览器或文件管理器“安装未知应用”，完成安装。

正式包与此前调试包独立安装，首次使用需要重新添加账号。之后的正式版保持相同签名，可直接覆盖安装并保留账号；请勿先卸载。

v0.2.4 及以前需先手动覆盖安装当前正式版。v0.3.0 及以上可在“设置 → 检查更新”中下载新版，并由系统确认安装。

当前版本已通过 Debug／Release 各 176 项单元测试、Lint、正式签名构建，以及 Android 12／16 各 28 项设备测试。新增检查覆盖流量下载的确认与取消、一次性授权、网络切换撤销授权及重试再次询问；模拟器已关闭 WiFi 验证移动网络查询和下载，真实手机运营商网络及计费行为仍待验证。

## 功能

- 应用内更新：手动检查版本，优先使用可上网的 WiFi；支持移动数据检查版本，流量下载前显示安装包大小并征求本次同意。下载允许后台继续，网络切换后暂停；系统确认覆盖安装后保留账号和设置。

- 首页账号下拉框：选择后设为默认账号，支持添加、编辑和删除，首个账号自动成为默认账号。
- 校园网资费：原“账号”标签改为“资费”，以四张卡片展示已用流量、可用流量、消费保护和账户余额，保留学校返回的单位和精度。
- 查询登录备用方案：自动登录未完成时询问是否改用内置网页登录，预填当前账号密码，由你点击学校页面登录；成功后返回原生资费卡片。
- 在线设备管理：展示所选账号的在线设备、IP、MAC、登录时间和在线时长；选择设备、确认后提交学校的注销操作。
- 本机加密存储：使用 Android Keystore 和 AES-GCM 保存账号、密码及设置，密码输入默认隐藏。
- 打开 App 自动登录：最多自动尝试一次；待发布 v0.3.3 支持已启动的认证在切换 App、按 Home 或锁屏后继续，结果只在 App 内展示。也可关闭自动登录或手动重试。
- 校园 WiFi 认证：支持公共 WiFi 和宿舍 WiFi 两阶段 IPv4 认证。
- 网络类型识别：根据已知认证服务的响应识别；有歧义时手动选择公共或宿舍 WiFi，并保存选择。
- 明确认证状态：已经认证时保持会话，不自动退出；失败后显示提示并停止自动重试。
- 宿舍联网确认：识别到有效宿舍认证服务后，提交密码前独立检查当前 WiFi 的 IPv4 外网；网关状态滞后、认证回复丢失或重复认证被拒绝后也会复核。验证已联网时停止提交认证，不把联网成功表述为两阶段均已认证。
- 校园服务仅使用 WiFi：校园认证与资费查询绑定实体 WiFi，网络切换时取消，不改走移动数据。资费查询离开前台即取消；待发布 v0.3.3 的认证可在后台完成本次任务。应用更新单独管理网络与流量授权。

## 使用方法

1. 在系统设置中连接北工大校园 WiFi。
2. 打开工小助，添加校园网账号和密码；首页下拉框可选择默认账号，也可进入“管理账号”修改已保存账号。
3. 回到首页，点击“登录 / 重试”；之后重新打开 App 时，自动登录会使用默认账号。
4. 若提示无法确定网络类型，在首页或“设置”中选择“公共 WiFi”或“宿舍 WiFi”，再手动登录。
5. 查看首页结果，并用浏览器打开外部网站确认可以上网。

修改默认账号用于后续登录，不会退出现有网络会话。认证失败后，检查账号、密码和网络类型，再手动重试。

### 待发布 v0.3.3：认证后台完成与提速

待发布版本已通过 Debug／Release 各 189 项单元测试、Lint 和固定签名构建。Android 14／16 各 41 项常规设备测试及通知设置恢复专项测试通过；Android 12 的 41 项中，40 项通过、1 项通知权限前提不适用而跳过。隔离模拟器覆盖安装保留账号、默认账号和设置。线上下载仍为 v0.3.2，验证详情见 [v0.3.3 说明](docs/releases/v0.3.3.md)。

认证开始后可以切换到其他 App 或锁屏。认证期间显示静默进度通知，可点击“取消认证”；首页也可取消。从最近任务中划掉工小助、断开或切换 WiFi 会停止本次认证，不会注销已建立的网络连接。

任务最长 75 秒，完成或失败后移除通知，结果只在首页展示。返回时复用运行中的任务；后台结束后的首次返回只展示结果，不立即再次认证。系统强制停止、杀进程或重启后不会自动恢复旧任务。

通知权限为可选项，拒绝后仍可认证；首页有通知授权和“打开系统通知设置”入口。多次拒绝后可在系统设置中重新开启，返回 App 后会刷新权限状态。服务与短时唤醒锁仅在认证任务期间运行，不做后台常驻或校园网保活。

资费页切后台时保留上次查询的四项数值、在线设备和查询时间，同时清除查询会话。返回后先确认当前 WiFi，再建立新会话查询；确认断网、换网或切换账号时清除旧数据，暂停监听本身不会清空显示。

公共／宿舍识别和两个 IPv4 外网检测改为并行，省去宿舍第一阶段前无效的二次认证查询；认证提交仍按阶段执行。首页“查看认证耗时”只显示固定步骤、毫秒数和结果，方便脱敏反馈。实际提速和校园后台联网仍待手机实测，不承诺固定秒数完成。

### 应用内更新

1. 连接 WiFi 或开启移动数据，在“设置”中点击“检查更新”。检查只读取版本信息，不自动下载 APK；App 不会自动检查或强制更新。
2. 查看版本号、更新说明、APK 大小和可用更新网络，点击“下载更新”。如果需要使用移动数据，会再次显示安装包大小，点击“同意并下载”才开始；取消会保留版本信息和已有进度。同意只用于本次下载，不会永久允许使用流量。
3. 可以离开 App 继续下载，通知栏显示进度；拒绝通知权限仍可下载，回到设置页查看结果。网络断开或切换、网络错误、应用被系统停止或设备重启后，下载会暂停。点击“继续下载”后，若使用移动数据会重新询问；服务器支持时续传，否则重新下载。“取消更新”会清理下载文件。WiFi 断开后不会自动切换到流量下载。
4. 下载完成后点击“安装更新”。首次需要在系统设置中允许工小助“安装未知应用”，再由系统确认覆盖安装。取消安装后 APK 会保留，不会自动再次弹出安装器。
5. 更新后重新打开 App，账号、默认账号和设置会保留，旧更新文件自动清理。请勿先卸载或清除应用数据。

安装前会检查 APK 的完整性、包名、版本、系统要求和固定正式签名。检查或下载失败时可手动重试，也可“打开发布页”使用浏览器下载；系统浏览器的网络由浏览器自行管理。调试版不提供正式包覆盖更新。

v0.3.1 修复了网络解析期间取消操作卡住的问题。只检查新版、尚未下载时，重新打开 App 会继续显示可下载；确实开始过的下载才会恢复为暂停。账号存储异常时也可进入设置页更新或打开发布页，原账号文件不会自动清除，账号设置暂时隐藏。

### 查询资费与注销设备

1. 完成校园网登录后，打开“资费”。首次进入该页会使用首页所选账号尝试登录学校自助服务；也可点击底部“登录查询”。
2. 四张卡片显示学校网页的返回值；未获取的字段显示“—”，不代表余额或流量为零。底部可“刷新资费”，时间标注用于识别上次查询的数据。
3. 学校要求验证码时，在 App 中输入图片中的四位验证码后登录；登录失败不自动重试，接口异常时可打开学校网页核对。
4. 在“在线信息”点击某设备的“注销此设备”，或点击底部“注销设备”选择设备，再确认。只有选中的会话会提交注销，相同会话的 IPv4／IPv6 行合并显示。
5. 注销本机会中断当前校园网连接；本次前台期间不会自动重新认证。需要恢复连接时，回首页手动登录。学校无感知认证可能让设备自行重连，具体按学校的注销提示处理。

切换默认账号后，旧账号资费和查询会话立即清除，点击“登录查询”查看新账号。资费查询登录与校园网认证是两个独立过程；查询成功不代表已经完成校园网认证。新功能的校园实测步骤见[资费与设备验证说明](docs/资费自助服务.md)。

学校自助服务需要单独的网页登录会话，接通校园网不会自动登录资费网站。App 的“登录查询”会使用已保存的账号完成这一步，无需先在浏览器登录；浏览器与 App 的查询会话彼此独立。

自动登录被拒绝或状态未确认时，可在弹窗中选择“网页登录”。内置页预填当前账号和密码，账号固定为首页所选账号；允许修改本次密码和填写验证码，修改不会保存。点击网页“登录”，查询成功后自动返回四张卡片。返回、切换账号或 WiFi、离开 App 会关闭该临时页面及会话。

网页登录未通过时，可在返回的登录页更正信息后再次提交；显示验证码时需填写四位，未填完整会给出提示，补齐即可继续。若发现查询页面账号与所选账号不一致，App 会清除查询会话、资费和设备列表，要求重新登录；不会继续用该会话注销设备。已由学校确认的前一次设备注销结果仍会保留在提示中。

“查看查询诊断”可展开请求阶段、HTTP 状态、页面类别和会话是否建立，方便提供脱敏反馈。回到登录页而无明确错误时显示“状态未确认”，不直接认定密码错误。无 WiFi、网络超时或设备注销失败不会自动打开网页登录。

## 账号与隐私

账号资料加密保存在手机本机，不做云端同步；登录时仅向固定校园认证地址提交选定的默认账号。账号数据排除系统备份和设备迁移，卸载应用或清除数据后需要重新录入。

学校参考认证协议使用 HTTP。本机加密保护手机中的账号存储，不代表认证请求的网络传输已加密。请求禁止跳转到其他地址，日志和错误提示不显示密码或完整认证 URL。

资费查询通过 HTTPS 访问固定学校自助服务地址 `https://jfself.bjut.edu.cn`，使用首页选定账号，保留正常的证书校验。查询 Cookie 和验证码只保留在内存，切换账号、网络或离开前台后清除；不导入浏览器 Cookie，不保存原始登录态网页，不同步账号或资费数据。校园认证和资费查询均绑定当前实体 WiFi；“打开学校自助服务网页”使用系统浏览器，网络与登录态由浏览器自行管理。

内置页只显示内存中的学校登录页面和资源，WebView 独立联网、Cookie、本地存储和缓存均关闭；验证码与登录提交沿用原生 WiFi 查询会话。密码页启用截图保护，网页内不能更改账号、充值、修改学校密码或注销设备。系统 WebView 缺少必要能力时提示更新，可使用系统浏览器入口核对。

宿舍网络的 IPv4 联网检查通过当前 WiFi 访问固定 HTTPS 地址 `https://connectivitycheck.platform.hicloud.com/generate_204` 和 `https://connect.rom.miui.com/generate_204`。待发布 v0.3.3 并行检测两个地址，任一确认联网即取消另一个；每个检测的 4 秒上限包含 DNS 和 HTTP。两个检测均不发送账号、密码或 Cookie，只接受正常 HTTPS 的 204 响应，不跟随跳转，不使用移动数据或 IPv6 验证 IPv4。检查失败只表示未确认联网，不等同于密码错误。

如果账号文件损坏或密钥不可用，App 会提示重试读取；明确确认清除后，才能重新录入，不会静默覆盖原数据。

更新仅访问本项目 GitHub Releases 及其官方附件服务器，通过独立的 HTTPS 客户端和所选实体网络通信，不向 GitHub 发送校园账号、密码或查询 Cookie。移动数据下载授权只在内存中保留，限定本次版本及网络，不会保存为长期设置。APK 与非敏感更新记录保存在应用私有目录，与加密账号资料分开；只向系统安装器临时提供已校验 APK 的读取权限。更新下载服务只在手动下载期间运行，不承担校园网保活。

## 常见问题

**没有 WiFi 或连接的是普通 WiFi？**

App 不负责自动连接 WiFi。先在系统设置中连接校园 WiFi；未识别到校园服务时，不会轮流提交已保存的账号。

**宿舍能上网，却提示二次认证失败？**

更新至 v0.2.1。旧版要求网关先返回“已认证”，才检查实际联网；网关状态更新较慢时便可能误报未确认，重试还会重复认证。新版在识别宿舍服务后先检查当前 WiFi 外网，认证响应异常后也会复核：确认已联网时显示“宿舍 WiFi 已联网（IPv4 已验证）”，按钮改为“检查联网状态”，不会再次提交密码。未确认的认证阶段会在提示中说明。若仍提示未完成，请关闭移动数据，用浏览器核对外网能否访问，并记录 App 提示；无法确认联网时不会把失败改报成功。

**反馈问题需要提供什么？**

记录 App 版本、手机型号、Android 版本、公共／宿舍 WiFi 类型、首页提示和实际能否上网即可。请勿在 Issue 或截图中提供真实密码或完整认证请求 URL。

**资费查询失败或注销后仍显示在线？**

先确认校园网能正常上网，核对首页所选账号；按提示手动重试或打开学校自助服务。注销结果未确认时，先刷新在线信息核对，再决定是否操作，避免重复提交。无感知认证可能使设备重新上线，App 不会替你关闭无感知或解绑 MAC。

若旧版显示“自助服务返回了不允许的跳转”，更新至 v0.2.2 后点击“登录查询”。学校的 `/Self/login/?302=LI` 登录跳转已加入兼容；其他异常跳转仍会停止，避免把账号发送到未知地址。浏览器能登录但 App 仍失败时，记录 App 版本和提示文字，提供脱敏反馈，不发送密码或 Cookie。

## 开发

使用 Kotlin、Jetpack Compose 和协程。需要 JDK 17 或 21、Android SDK Platform 36 和 Build Tools 36.0.0。

在被忽略的 `local.properties` 中配置 SDK，例如：

```properties
sdk.dir=D\:/Applications/Development/Android/Sdk
```

Windows PowerShell：

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
```

macOS／Linux 使用 `./gradlew`。连接独立测试模拟器后，可运行 `:app:connectedDebugAndroidTest`；界面测试会清除调试版账号，请勿在存有真实账号的设备上执行。

GitHub Actions 自动执行测试、Lint 和构建，版本标签触发正式签名与 Releases 发布。[发布与签名说明](docs/发布.md)介绍固定签名、覆盖更新和回滚约定。

当前不包含后台常驻、定时保活、IPv6 认证、运营商选择、云端同步或自动连接 WiFi。
