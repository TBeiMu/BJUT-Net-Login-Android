# 资费查询与在线设备

工小助 v0.4.8 正式版提供北京工业大学[计费系统自助服务](https://jfself.bjut.edu.cn/Self/dashboard)查询。用户已确认正式版主要功能可用，本页介绍当前操作与边界。

## 查询

在“我的 → 校园网账号”选择默认账号，然后进入“资费”。首次进入可自动查询，底部可手动“登录查询”或“刷新资费”。接通校园网与登录资费网站是两个独立会话，不读取系统浏览器的 Cookie。

当前源码将查询状态放在右上方、“可用流量”卡片上方。提示区始终保留两行文字及加载标识的空间，四张卡片的数值和单位也预留共同高度；查询中、完成或错误提示的变化，以及数据载入，都不会推动下方查询和管理按钮。长提示可点击查看全文。此布局调整尚未发布对应 APK。

学校要求验证码时，填写本次图片中的四位验证码；提交前不会重新生成图片。自动登录未完成时，可选择内置网页登录：预填所选账号和密码，由用户点击登录；修改本次密码不会写回账号存储。返回、切账号、切网或离开前台时清除临时会话。

## 四项资费与设备

| 卡片 | 数据来源 |
| --- | --- |
| 已用流量 | 学校当前计费周期的已用值及单位 |
| 可用流量 | 学校返回的剩余值或“不限量”等文本 |
| 消费保护 | 学校返回的设置或金额 |
| 账户余额 | 学校返回的金额，保留小数精度 |

缺失字段显示“—”或“未获取”，不编造零值。页面保留账号摘要、查询时间和必要错误，不常驻诊断或技术说明。离开前台保留上次数值和时间，但清除 Cookie；确认断网、换网或切账号时清除旧展示数据。

在线设备显示 IPv4／IPv6、MAC、登录时间、在线时长和使用流量。同一会话的重复 IPv6 行合并，流量不累计。设备列表读取失败明确提示，不能显示成“没有设备”。

2026 年 11 月 11 日只读核对学校流量列：对 `downFlow`、`upFlow` 分别取整数，相加后除以 1024，显示 MB 和三位小数。缺失、负数、异常或重复行冲突时显示“未获取”，不使用账户总流量代替设备流量。

## 注销设备

1. 点击单台设备的“注销”，或底部“注销设备”后选择一台。
2. 核对设备信息与学校提示，确认后提交一次下线操作。
3. 学校确认后刷新在线列表；若断网导致结果未确认，先重新查询核对，避免重复操作。

注销前先停止并等待进行中的校园认证清理。注销本机后本次前台期间不自动重新登录，需要时到校园网连接页手动恢复。学校无感知认证可能自行重连，App 不代替用户关闭无感知、解绑 MAC 或批量踢设备。

## 网络与会话

资费请求仅通过当前实体 WiFi 访问 `https://jfself.bjut.edu.cn`，保留平台 TLS 校验，不转用移动数据。凭据只发往已识别的同源登录接口，失败后不自动重发。查询 Cookie、验证码和动态校验字段仅在内存保留。

登录读取实际页面地址及动态字段，隐藏验证码也先初始化同一会话；返回登录页而无明确错误时提示状态未确认，不直接判定密码错误。内置页使用限定来源消息接口，只接受当前会话、已校验表单的提交；禁止跨站导航及网页内注销设备。查询完成前核对返回账号与所选账号一致。

接口为 `dashboard/getOnlineList`、`dashboard/getOfflineTip`、`dashboard/tooffline`；下线参数由选中会话取得，禁止自动跳转、批量操作和重发。原始登录态页面可能内嵌密码和个人信息，不保存为测试样本或日志。

## 验证与反馈

2026 年 11 月 13 日完成查询提示与按钮布局检查：Debug Lint、Debug APK 和设备测试 APK 构建通过；Android 16 隔离模拟器执行 `BillingUiTest` 与 `AccountUiTest` 共 8 项测试，全部通过。360dp 宽度下分别使用默认与 1.8 倍字号，检查空提示、两种查询中提示、查询完成、长错误及清除提示，四卡片与查询／管理／注销按钮的实际坐标和尺寸保持一致；从占位符载入数字、中文值及单位也不移动按钮。已查看深色模式下两种字号的查询中与错误截图，并验证长提示全文、关闭与状态更新清理、弹窗遮挡报告及查询期间禁用重复操作。

本轮只调整显示布局，验证码表单、查询和设备注销流程沿用原行为；以上检查使用虚构数据，未新增真实手机、Android 12／14 或校园联网实测。未发布 Release，版本仍为 v0.5.1／versionCode 32。

正式版可用性由用户确认；自动化检查另使用虚构页面与账号验证验证码、特殊字符编码、错误分类、Cookie、会话隔离、重复操作和设备流量。该记录不表示所有学校账号、设备下线和网络组合均逐一实测。

反馈提供版本、网络类型、提示文字及脱敏截图即可，不提供密码、Cookie、会话 ID、完整登录地址或原始网页。学校字段变化时按错误提示使用学校自助服务核对。历史发布记录见 [v0.4.8 更新说明](releases/v0.4.8.md)。
