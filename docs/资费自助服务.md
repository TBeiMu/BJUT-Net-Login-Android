# 资费查询与在线设备

工小助 v0.2.0 接入北京工业大学[计费系统自助服务](https://jfself.bjut.edu.cn/Self/dashboard)。本功能沿用首页所选账号，加密账号格式与旧版兼容，不需要重新录入。

## 功能与边界

- 资费页四张卡片读取已用流量、可用流量、消费保护和账户余额；不换算学校的单位，不丢弃余额的小数精度，允许“未设置”“不限量”等文本。
- 查询会话与所选账号和实体 WiFi 绑定。离开前台后清除 Cookie，保留带查询时间的上次展示数据；切换账号或 WiFi 后同时清除展示数据。
- 校园网上网认证与学校资费网页登录是两个会话；“登录查询”使用 App 已保存的账号登录自助服务，不要求先在浏览器登录，也不读取浏览器 Cookie。
- 资费页首次进入前台可自动查询一次；失败后需要手动操作，验证码由用户填写。切换账号后点击“登录查询”。
- 在线设备按会话合并，保留 IPv4、IPv6、MAC 和在线时间。设备列表读取失败会明确提示，不显示成“没有设备”。
- 底部“注销设备”需要先选择设备，再确认；每次只提交一个会话，不自动注销，不批量踢设备，不自动重发下线请求。
- 注销本机会中断 WiFi 上网。App 暂停本次前台期间的校园网自动认证；学校无感知认证的行为由学校系统控制，不自动更改无感知设置或解绑 MAC。
- 下线响应成功但后续查询失败时，分别说明“学校已确认设备注销”和“刷新失败”；请求中途断网时显示结果未确认，需要先核对在线信息。

## 接口依据

2026 年 11 月 4 日只读核对了学校网页的登录表单、资费字段及在线设备操作代码，未执行真实设备注销，也未使用浏览器中的真实凭据进行自动化登录。

当前实现 GET 登录表单、POST `account`／`password`／动态 `checkcode`／用户填写的 `code`，仅允许受限的同源跳转。学校当前表单显式禁用 SM3；检测到密码提交方式变化时停止提交，不猜测新协议。验证码读取同源 `login/randomCode`。

v0.2.2 修正用户反馈的“不允许的跳转”。2026 年 11 月 4 日重新只读请求未登录的 dashboard，确认学校返回 HTTP 302 到同源 `/Self/login/?302=LI`，随后为正常登录表单。兼容登录页末尾斜杠及仅含 `302=LI` 的已知参数；不允许任意返回地址参数、跨站地址或 HTTPS 降级，不将密码转交给未知接口。验证只读取未登录页面并在内存处理动态字段，没有提交真实或虚构登录凭据。

资费按 `dl` 中的中文标签及其数值、单位提取。网页账户刷新使用页面的动态校验字段，再读取 dashboard；刷新未确认时不把旧数据说成最新。在线设备读取 `dashboard/getOnlineList`。设备注销沿用网页的 `dashboard/getOfflineTip` 提示及 `dashboard/tooffline` 请求，参数为选定设备的 `sessionid`、`ip` 和去掉连字符的 `mac`。设备注销禁止跳转，不因会话失效而重试下线操作。

请求使用已有 WiFi 的 SocketFactory 和 DNS，校验证书，不改走移动数据，不跟随跨站跳转；查询会话仅在内存，不存入本机文件或系统备份。学校的原始登录态 HTML 可能包含账号密码和个人资料，不能作为反馈附件或测试样本保存。

## 校园手机实测

自动化测试使用虚构 HTML、JSON、账号和会话，覆盖登录、验证码、特殊字符编码、查询会话隔离、响应异常、取消请求及设备选择。真实手机上新增资费查询和下线操作仍待验收。

用户在校园确认旧版查询被登录跳转拦截，v0.2.2 修正后仍需按下面步骤复测，不能把网页登录页可访问或模拟登录成功当成资费查询已通过校园验收。

建议按以下顺序核对：

1. 覆盖安装新正式 APK，确认原账号、默认账号和设置仍可读取。
2. 在校园公共 WiFi／宿舍 WiFi 分别关闭移动数据，先确认网页能够上网。
3. 用同一账号打开 App“资费”和学校 dashboard，核对四个数值、单位和余额精度；点击刷新后再次核对。
4. 使用两个测试账号，切换首页默认账号，确认旧数据清空、新查询不混入旧账号设备。
5. 检查验证码、密码错误、暂时断网、WiFi 切换和返回前台的提示，确认失败不反复提交密码。
6. 核对在线设备；先选择“取消”，确认设备未下线。再选择一台可中断联网的测试设备，确认注销后核对学校在线列表及该设备联网情况。
7. 注销本机时确认不会由 App 立即自动重新认证；核对学校无感知认证提示，如自行重连，使用学校提供的方式处理。

反馈仅提供版本、网络类型、提示文字及脱敏截图。不要提供真实密码、完整登录 URL、Cookie、会话 ID 或原始登录态网页。
