# 课程添加与编辑验证

日期：2026 年 11 月 13 日。基于源码 `bac9981`，实现课表添加菜单、自定义本地学期及学校／自定义课程编辑。版本仍为 v0.5.1／versionCode 32，本轮仅推送源码，不打标签、不发布 Release；公开 APK 尚不包含本功能。

## 行为与资料

- 今日、整周和空课表的右上角“＋”先展开三个选项，本科生导入禁用并标注暂未开放；研究生选项复用现有登录、网络及后台导入；自定义课程打开原生弹窗。状态条继续／重试及课表管理的研究生入口仍直接使用原流程。
- 自定义课程输入名称、可选教室／教师、星期、周次及 1–20 节区间。首次无学校课表时先选择第一周周一和周数（默认 20），本地学期与首条课程一起加密保存。未保存草稿旋转可恢复，关闭或进程重建不自动保存。
- 学校和自定义课程详情均可编辑、删除。默认仅本次，可选同一课程、同一星期节次的其他周次；编辑分别选择原范围和目标安排。未修改节次区间时保留原非连续节次，重叠仍沿用详情列表。
- 学校资料与本地学期／课程分别记录在原加密课表库。旧 schema 1 缓存的新增字段默认空，继续使用原 Keystore、AES-GCM 和 AtomicFile，资料排除备份；纯本地显示不创建学校身份。
- 首次完整导入成功时将初始本地课表按学校周次对齐。超出学校周数的记录保留，在管理页可移动或删除；后续新学期或换账号不自动搬移旧自定义记录。普通解绑保留本地资料，损坏库清除仍需确认。
- 学校课程本地修改在完整刷新成功后被学校新资料替换，失败、暂停和取消保留。自定义课程保留，旧学期可在管理页选择查看并继续管理。保存复核原完整资料，防止旧草稿写入已刷新的课表；任务运行时禁用编辑。

最终独立界面组两台各 24 项全部通过；后台组 API 36 为 7 项通过，API 31 为 6 项通过、1 项版本不适用跳过，共 61 项适用检查通过。两组在独立 instrumentation 进程运行。
