# 课表跟手翻页测试包

当前版本 **0.4.11-test2／versionCode 28**（test1 为 versionCode 27），分支 `codex/schedule-follow-drag`。

本包用于体验课表手感，尚未公开发布。GitHub Release 和 App 内版本源继续为 v0.4.10；后续正式 v0.4.11 采用 versionCode 29，支持覆盖本测试包。

## 安装与使用

测试包沿用正式包名和签名，从本次提供的本地 APK 安装，直接覆盖 v0.4.10 或 test1。不要先卸载或清除应用数据，账号、默认账号、课表、壁纸及设置保留。

- 向上划下一周，向下划上一周；手势识别后课程立即跟手，相邻周进入。
- 慢拖超过课程区域高度的 25%，或快速划动，即翻一周；较短拖动平滑回弹。
- 一次手势最多翻一周，首末周不循环；反向拖动和中途停住均同步响应。
- 星期、节次和时间固定，日期按课程翻页进度移动；标题、右侧圆点及今日标记在翻页完成后更新。
- 课程静止时点开详情；拖动后不误开。后台、旋转、切页或弹窗遮挡取消未完成翻页。

test2 另外优化连接提示：确认无实体 WiFi 时显示“未连接WiFi”约 1 秒后恢复周次，跳过认证；认证确认成功立即替换等待或超时，不保留旧文字淡出。标题等待期限改为 3.5 秒，超时提示仍约 1 秒，真实认证时限不变。

安装后重点体验轻划、停住松手、反向拖动、连续上下划以及动画中再次拖动。反馈手机型号、字体设置和可复现动作即可，不需要账号密码。

## 验证记录

Debug／Release 各 **273 项单元测试**、两种 Lint 和固定签名构建通过。Android 12／14／16 隔离模拟器各 **30 项相关检查**通过；旧动画隔离及旋转／切页恢复加固后，Android 12／14 另复跑 10 项手势检查，Android 16 使用最终实现完成全组检查。

使用虚构课表验证分段触摸中的位移、日期同步、固定栏节点、25% 阈值与停住松手、快速翻页、阻力回弹、动画接管、课程点击、后台取消、旋转、过期动画、空周、重叠课和第 13 节，并检查浅色、深色、小屏、大字体实际绘制。测试夹具的背景文字继承与真实 Scaffold 不完全相同，不修改已有主题配色。Android 12 另对最终签名包注入分段手势，确认松手前课程已移动、短拖回弹、超过阈值翻周及固定栏保持原位，核对实际显示截图。

同签名 v0.4.10 → 0.4.11-test1 覆盖安装，确认虚构账号、默认账号、设置、完整课表、图片壁纸与模糊配置保留，原加密文件、图片及外观配置摘要不变。测试样本全为虚构资料，手机手感仍由用户体验确认。
