# 认证成功与请求清理分离验证

日期：2026 年 11 月 14 日。基于 `9911517`，修复 v0.5.3 发布后审查发现的认证成功提示被另一端请求清理拖延的问题。按长期授权提交并推送 `main`；本次不打标签、不发布 Release，不修改 v0.5.3／versionCode 34 或线上 APK、版本元数据。

该源码修复随后经用户审查并单独授权发布，已于同日合入 v0.5.4／35；发布和公开附件结果见 [v0.5.4 验证记录](v0.5.4验证.md)。下文保留源码维护阶段的验证事实。

## 原因与修复

v0.5.3 在任一校园端点明确确认在线后会取消另一端探测，但协程仍须等待该请求清理完成才返回。控制器原来只在认证函数返回时发布成功，因此清理较慢时，界面的 3.5 秒等待期限仍会触发“登录超时”。

新增结构化在线确认回调，所有成功路径均在确认时发布结果；控制器区分已经确认成功与任务是否仍在清理。确认后立即显示“校园网已连接”，原请求继续清理，保持 `running=true`、前台服务及任务槽；清理结束后才解除运行状态。普通进度文字不参与结果判断。

同任务重复确认或迟到进度不会重置成功计时；清理异常、认证期限到达和后续失败不会降级已经确认的成功。手动取消、账号失效、服务停止、WiFi 切换或断开仍使旧结果失效；所有确认和进度回调在控制器作用域内再次核对原任务与 WiFi。凭据提交目标的识别规则、单次提交和不自动重试规则保持。

## 自动检查

使用项目 Gradle Wrapper：

```powershell
.\gradlew.bat :app:testDebugUnitTest :app:testReleaseUnitTest :app:lintDebug :app:lintRelease :app:assembleDebug :app:assembleDebugAndroidTest "-Pkotlin.incremental=false" --console=plain
```

Debug **377 项**、Release **371 项**单元测试通过，无失败、错误或跳过；Debug／Release Lint、Debug APK 和设备测试 APK 构建通过。关闭本次 Kotlin 增量编译，确保认证监听器接口变更后的调用端全部重新编译。

新增 `ConfirmedLoginCleanupTest` 的 **10 项**回归覆盖公共／宿舍任一端提前成功、真正晚成功、提示遮挡、清理异常、认证期限、取消后任务槽、换网、旧回调、重复回调及未确认／歧义结果。使用虚构响应与虚拟时间，核心过程如下：

| 时间／条件 | 修复后结果 |
| --- | --- |
| 0ms 开始认证 | 显示“正在登录校园网” |
| 200ms 任一端明确已认证 | 立即显示“校园网已连接”，取消另一端，不读取凭据 |
| 2200ms 成功提示到期 | 恢复课表标题，任务仍等待清理 |
| 3500ms 原标题等待期限 | 不显示“登录超时”，不恢复登录进度 |
| 3800ms 另一端清理完成 | 释放运行状态，不重播成功提示 |
| 成功已确认，清理跨过 60 秒认证期限 | 保留成功，62.2 秒清理完成；未超过 75 秒任务上限 |
| 实际直到 3800ms 才确认在线 | 3500ms 可先提醒超时，确认时立即替换为成功，旧超时计时不清除成功 |
| 200ms 成功后取消或切换 WiFi | 立即丢弃旧成功，清理完成前不能开始新认证，旧回调不能复活 |

审查时隔离复现的“200ms 已确认，但清理到 3800ms 才结束”断言，修复前失败、修复后通过；已用仓库内的新回归用例覆盖，隔离审查文件不提交。

## 设备验证

在 Android 12／API 31、Android 16／API 36 隔离模拟器中，分别执行：

- `CampusTitleImmediateTest`：4 项，包含新增的真实课表组件、认证控制器与模拟慢清理传输联合测试。
- `CampusTitleLifecycleTest`：5 项，验证标题及课表固定位置、后台完成后返回、快速失败、旋转后的 3.5 秒期限和真正迟到成功。
- `CampusLoginServiceTest`：9 项，验证后台与锁屏、旋转复用、通知取消、最近任务移除、旧启动重放、服务超时、断网和更新服务隔离。本轮明确排除通知拒绝前提的单独用例，未重新验证该场景。

两台模拟器各 **18 项通过**，无失败或跳过。新增界面用例确认 200ms 已显示成功且任务仍在运行，3500ms 无超时，3800ms 清理完成后不重播。测试仅安装独立 `.debug` 包并使用虚构资料；Android 16 使用本次独立数据目录，不改原模拟器资料。日志保留在被忽略的 `app/build/confirmed-login-cleanup/`。

本轮未使用真实学校账号重新验证校园联网，未执行真实手机或正式签名包覆盖安装。模拟响应与虚拟耗时用于验证状态和时序，不代表实际公共或宿舍网络的耗时与连通性。
