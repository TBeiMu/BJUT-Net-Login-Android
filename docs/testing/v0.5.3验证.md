## 发布前检查

使用项目 Wrapper 执行 Debug／Release 单元测试、两种 Lint、Debug APK、设备测试 APK 和固定签名 Release APK 构建，最终全部通过。Debug **367 项**、Release **361 项**单元测试，无失败、错误或跳过。

本地正式包经 `aapt` 与 `apksigner` 核对：版本 0.5.3／34、包名 `io.github.tbeimu.gongxiaozhu`、minSdk 31，证书 SHA-256 与 `release-signing.sha256` 一致。大小 **4,365,718 字节**，SHA-256 为 `719086a0715104fc7ff7e84787ab22bbaf6252be85dd907645edaa771db3b49d`；这些值仅描述本机测试包，公开附件以发布工作流实际生成的 APK 为准。

Android 12／API 31 与 Android 16／API 36 隔离模拟器均安装从 GitHub 下载、摘要已核对的实际 v0.5.2 APK。固定签名测试工具写入虚构账号、默认账号及设置、9 周学校课表、4 次原有自定义安排、图片及外观配置，再覆盖安装本地正式 v0.5.3。启动并停止 App 后，账号、课表、壁纸图片及外观配置的 SHA-256 均不变，资料可解密读取；准备与覆盖核验各 1 项通过。

启用 R8 的实际正式包在两个模拟器各通过 1 项界面流程：本科导入禁用且没有学校登录跳转；创建“正式包多日课程”，选择周一、周三并保存为两次安排，原自定义和学校课表保留；整周课程可打开详情，外层标题移除，编辑／删除／关闭同排且关闭靠右；重新打开个人页显示默认备注，课表管理能读取已保存课程。已查看两个系统的实际课程详情与个人页截图，覆盖浅色和深色／1.3 倍字号环境。

Android 16 首轮正式包测试的课程已保存，但测试在保存状态切换期间继续操作，并按没有换行的课程名查找网格；大字体网格的实际文本包含分行，因此两次等待失败。隔离测试工具现等待编辑弹窗完全关闭，查找时忽略排版换行，清理本次失败测试生成的虚构课程后，完整流程通过。调整只作用于被忽略的测试工具，没有更改正式 App 来绕过检查。

本机正式包、测试工具、模拟器日志和截图位于被忽略的 `local/release-v053/` 与 `local/visibility-runner/`。所有资料均为虚构；本轮未使用真实账号进行校园联网验收，未在真实手机新增覆盖安装验证。宿舍无需二次认证依据用户当前明确说明，其他设备与校园实际使用仍以反馈为准。
