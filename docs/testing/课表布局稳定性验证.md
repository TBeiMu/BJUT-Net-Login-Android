## 修改

- “今日／整周”按钮原先分别距底部 18dp / 14dp，切换造成 4dp 位移；现在共用右侧 20dp、底部 18dp 的锚点，按钮节点保持复用。
- 标题原先只设置共同的 44sp 行高，但 17sp / 38sp 混排周次的实际字体高度仍可能更大，并带动上方小字重新居中。现在测量静态标题与校园网提示的真实高度，预留共同空间；整周视图的小字顶部对齐。
- 保留周次数字的视觉样式、字号适配及校园网提示的原有计时、成功立即替换和任务结果处理。
