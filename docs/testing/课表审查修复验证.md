# 课表审查修复验证

日期：2026 年 11 月 13 日。

本轮基于 `43d42e0` 修复三项审查问题，修复提交为 `b3d9937`。用户在本地提交完成后追加授权推送源码到 GitHub `main`。版本仍为 v0.5.1／versionCode 32，不打标签、不发布 Release；公开 v0.5.1 APK 不包含此批修复。

## 修复内容

1. **CAS 密码不重复提交。** 密码 POST 使用不可重放的请求体，阻止 OkHttp 对 `503 + Retry-After: 0` 的隐式重发；307／308 仍拒绝重放，登录失败后等待用户重新操作。
2. **取消后等待完整清理。** HTTP 回调结束并关闭响应后，请求协程才完成。会话关闭同时取消 HTTP、DNS 和登录页资源，并提供异步清理等待；控制器清理期间保留任务槽和运行中任务的服务标识，新会话及未完成进度删除均等待旧清理结束。关闭尚未提交的登录页也执行该等待。
3. **今日随日期更新。** 默认选择跟随上海日期，跨天、跨周、返回前台和状态恢复后显示当日；用户主动浏览其他日期时保留选择，选回今天后恢复跟随。日期改变后的左右划动从当前显示日计算。

账号、课表加密格式、网络选择、正式签名、版本元数据和开屏／加载动画均未修改。
