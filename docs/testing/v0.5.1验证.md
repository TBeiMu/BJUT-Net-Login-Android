# v0.5.1 验证记录

本次基于 GitHub 主分支 `25e8b84`，发布 v0.5.1／versionCode 32。用户授权更换附件小鸟 Logo 并发布新版本，随后明确开屏和加载标志保持原样。

## 图像与变更范围

- 桌面彩色前景保留附件像素，按 Android 自适应图标安全区域居中；浅色底图在深色模式也保持原色。
- 关于页使用原图的缩小版本。主题图标和通知图标由原图色块轮廓派生，保留脸部及眼睛的负空间。
- `ui/Brand.kt`、`splash_mark.xml`、`splash_mark_animated.xml` 及开屏主题配置与仓库最新源码保持一致，原开屏和加载动画继续使用“工”。
- 不更改账号、课表或外观的加密格式、包名、网络协议、更新地址、依赖和权限。
