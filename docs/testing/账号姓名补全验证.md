## 行为

- 首次新增校园网账号时，备注留空才登记一次自动姓名查询；自定义备注保留，包括用户主动将学号填写为备注的情况。
- 等待课表缓存读取完毕，优先按相同学号使用已经验证并保存在本机的姓名，无需网络或密码提交。
- 本机没有对应姓名时，等待 App 在前台，并取得可上网的实体 WiFi，或同一 WiFi 已完成校园认证，再发起一次独立的学校身份查询。只处理新增账号登记的待处理请求，不给升级前的历史账号自动补发凭据。
- 姓名查询仅使用学校身份接口及 CAS 登录，不读取学期或课程，不绑定或更换课表账号。DNS、HTTP 均绑定同一 WiFi，禁用 VPN、代理及移动数据回退；会话与课表、认证及资费隔离。
- 凭据提交前先校验学校 CAS 表单。已识别到验证码要求时停止；密码只提交一次，保留不可重放请求体和 307／308 拦截。返回登录页、失败或超时后不自动重试。
- 单次网络查询最长 30 秒；离开前台、切网、编辑／删除账号或账号存储不可用时取消并等待清理。结果须匹配原账号 ID、学号和密码快照，且备注仍可自动填写，才允许保存。
- 姓名尚未取得时保留账号和默认备注。之后导入课表、学校确认学号并保存绑定身份后可补全，不必等整个学期导入结束。姓名为空、异常、过长或账号不匹配时不覆盖。
- 姓名保存在现有账号加密文件的备注字段；自定义备注标志与一次查询标志也使用原 Android Keystore／AES-GCM 加密。旧账号格式兼容读取，不增加明文姓名文件或密码副本。
- 自动更新备注会同步到界面，不切换默认账号。可选姓名写入失败后，重新读取、解密并核对原账号文件；确认原资料仍有效时，只在无遮挡、非忙碌的前台给一次“姓名暂未保存，校园网账号仍可使用”提示，不取消认证或清除资费。文件损坏、密钥不可用或写入结果无法确认时仍阻断账号操作，并丢弃先前尚未展示的“账号仍可使用”提示。
- 写入失败的账号不会随进度刷新、WiFi 状态或前后台切换连续重试。新的课表身份数据或用户结束编辑可再次尝试本地保存；已经消费的联网凭据提交不会重发。
- 本地补全、联网结果和一次尝试标志都在取得仓库锁后检查任务有效性，并在校验原资料和加密完成后、写入前再次检查。缓存补全绑定原账号 ID，已取消的排队 I/O 不能更改编辑草稿背后的备注或重建的同名账号。

## 姓名写入审查修复

修复两项已复现问题：辅助姓名写入失败误触发全局存储阻断；已取消的本地姓名 I/O 在等待仓库锁后仍写入，进而与编辑草稿交叉、导致只修改密码也会丢失姓名。

常规测试新增 13 项，覆盖原账号完好时的备注／标志写入失败、文件或密钥在失败期间损坏、一次提示消费及过期提示丢弃、无连续写入重试、新课表身份到达后恢复本地保存，以及取消发生在仓库锁等待或加密期间的行为。锁竞争测试使用真实线程与仓库监视器，分别检查本地姓名写入、联网结果和一次尝试标志；不修改密码、默认账号或有效的自定义备注。

原审查目录 `app/build/name-review` 中的两项独立复现测试也已重跑通过。该目录被 Git 忽略，正式回归覆盖已写入源码测试，不依赖构建目录文件。

## 实际学校接口与验证边界

在当前电脑的学校会话中已读取身份接口，确认 `d.base.realname` 和 `d.base.role.number` 实际存在，姓名与门户显示一致。无登录态时接口返回 `e=10013` 及 `/uc/wap/login` 登录入口；学校移动登录页通过已校验主表单提交账号和密码。
