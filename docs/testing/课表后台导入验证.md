# 课表后台导入验证

日期：2026 年 11 月 12 日。基于 v0.5.0 / versionCode 31 的维护修改；最初仅在本地验证，用户随后授权将本轮维护代码推送，但仍不创建新标签或发布 Release。本次不修改版本号或发布附件，线上 v0.5.0 安装包的行为不变。

用户随后反馈后台导入问题“已修复”。以下保留当次构建与专项检查结果，不代表所有手机和校园网络场景已验证；当次调试包路径可能被后续本地构建覆盖。

## 行为

- 在可见页面点击导入或提交学校登录时，先启动独立 `dataSync` 前台服务，确认服务启动后才发送学校请求。启动确认最多等待 5 秒；失败不会提交或重试凭据。
- 已启动的请求、整学期导入、内存学校会话和课表网络监听由应用级运行时持有。切换 App、锁屏及旋转后继续，返回复用原任务；后台完成后保留结果并停止服务和监听。
- 尚未提交的学校登录页仍在离开前台时关闭。已提交的请求若返回需要人工登录的页面，则清理会话并暂停，等待用户手动操作。
- 通知仅显示进度和暂停按钮，不含学号、姓名、密码、Cookie 或学校页面。点击返回课表，结束自动移除；拒绝通知权限不取消任务。
- 主动暂停、断网、切换实体网络、从最近任务划掉、系统停止或达到 30 分钟上限时停止导入，清理会话并释放唤醒锁；保留已解析进度与旧完整课表，不自动恢复或重试。
- 暂停状态先于请求取消发布，避免主线程同步完成清理时短暂出现“任务已结束但仍显示导入中”。旧通知、旧服务回调和迟到学校响应不能操作新的任务。
- 校园认证、资费和更新会话仍使用各自的网络与生命周期。没有新增依赖、权限、持久化会话、后台常驻或自动重启。

## Android 专项检查

使用只读、无窗口的 Android 12 / API 31、Android 14 / API 34、Android 16 / API 36 模拟器；安装 `.debug` 包，学校身份、课程、页面和网络会话均为虚构资料。

`ScheduleBackgroundServiceTest` 使用真实 Android 前台服务、Activity 生命周期、通知 PendingIntent、屏幕休眠和加密存储，检查：

1. 后台完成整学期，返回不重启请求，服务和通知释放。
2. 旋转与多次前后台切换复用同一任务。
3. 熄屏期间完成导入，无需先解锁。
4. 后台失去网络时暂停、保留进度，不接受迟到结果。
5. 通知暂停，旧通知不能取消下一次导入。
6. 从最近任务移除 App 后停止服务并保留进度。
7. Android 16 缩短 `data_sync_fgs_timeout_duration` 后由系统触发 `onTimeout`，验证及时停止与进度保留；结束恢复原配置。Android 12 / 14 不具备该系统回调，跳过此项。

另执行原有学校 WebView 登录导入与取消导入的三项回归。测试夹具在替换缓存后显式刷新共享运行时，并在检查原生周视图前切换“整周”，适配现有 v0.5.0 默认今日界面。
