# 研究生课表（v0.4.1）

## 导入和日常查看

1. 连接可上网的 WiFi 或开启移动数据。课表优先使用可上网的 WiFi，仅有流量时也可登录和导入，无需先连接校园网；页面会显示选用的网络。
2. 打开“课表”中的“导入研究生课表”。在学校统一身份认证页面输入自己的学号、密码和学校要求的验证码，完成一次登录。密码不会保存。
3. App 从学校确认学号和当前学期，自动获取整个学期，显示总体进度，无需用户逐周选择或确认。请保持前台，完成后自动返回原生课表。
4. 完成后打开和切周无需登录，可离线翻周、选择周次、返回本周；点击课程块查看地点、教师和节次。重叠课程点击后显示完整列表。
5. 手动“刷新”时重新登录学校。完整新课表导入前仍显示原课表，失败不会覆盖旧课表。

导入切后台、断网、WiFi／移动数据或其他实体网络切换后会暂停，保留已解析的周次；返回后点击“继续导入”，重新登录同一学号和学期后继续。学校返回其他学号时停止并作废旧进度；学期变化则重新导入当前学期。初次导入尚未完成时显示进度，不能把未获取周次当成无课。

请求超时会显示连接错误并清除临时登录会话，不停留在“正在登录”或过期进度提示；原有完整课表和已取得的进度会保留，等待用户手动重试。不会自动重复提交密码。

“本周”按上海时区计算。返回前台、日期变化和点击“本周”时会更新日期，不需要重新导入课表。

如果旧版登录页仅显示顶部文字、账号密码区域持续白屏，请升级至 v0.4.1。新版修复了网页布局造成内嵌登录框高度为零的问题；通过覆盖更新即可，账号和设置会保留。

课表账号独立于校园网默认账号。切换校园网账号不会切换课表。更换或解绑课表账号，在“我的”点击“更换 / 解绑课表账号”并确认，清除本机课表后重新导入；原校园网账号和设置保留。

## 页面与数据

底部固定为“课表／资费／我的”，默认显示课表。“我的”包含课表绑定、校园网账号和联网操作、壁纸、设置、应用更新与关于。认证和更新通知会跳转至各自的操作位置。

学校公开前端已核实的接口为：

- 学期及周数：`/yjskb/wap/default/get-index`。
- 周视图：`/yjskb/wap/default/get-datatmp`，提交学校返回的学年、学期、周次和 `type=2`。
- 学工号核对：`/uc/wap/user/get-info`，优先使用 `base.role.number`；姓名使用 `base.realname`。

课程日期、节次和详情以实际返回为准；没有提供具体上下课时间就只显示节次。任何无法识别的核心字段都会停止导入并保留旧课表，不拼造课程或零值。

## 本机保护

课表与未完成进度使用独立的 Android Keystore 密钥和 AES-GCM 文件，排除备份。只保存规范化课程、绑定信息和更新时间，不保存登录态网页、密码、Cookie 或验证码。数据损坏或密钥不可用时提示重试，用户确认清除后才可重新导入。

学校登录页、资源、验证码和课表请求由绑定选定实体网络的原生会话处理，优先使用可上网的 WiFi，也支持移动数据。DNS 与 HTTP 使用同一网络，排除 VPN；已开始的请求不会在切网后自动转移或重发。WebView 自行联网及持久化存储关闭。为兼容学校移动端页面，只提供页面内存中的偏好对象，页面关闭即释放。

课表网络与其他模块独立。校园网认证和资费查询仍只使用 WiFi；应用更新的移动数据 APK 下载确认规则不变。

壁纸通过系统照片选择器导入，限制文件大小并重新编码后保存在应用私有目录；可随时恢复默认背景。

## 验证状态与校园验收

已使用虚构数据验证解析、一次登录自动导入整个学期、断点继续、旧课表保留、独立加密存储、页面跳转、重叠课程和壁纸。登录页除检查元素加载外，也核对内嵌页面的可见高度和实际绘制，避免把“已加载但白屏”当作通过。当前版本验证明细见 [v0.4.1 更新说明](releases/v0.4.1.md)。

**待真实账号验收：**分别使用 WiFi 和仅移动数据完成学校登录与整学期导入，核对当前周、第一周、最后一周及无课周的日期、课程、节次、教师和地点；核对学期周数；切后台或切网后继续导入；刷新失败时确认旧课表仍在；双网络开启时核对课表优先选择可上网的 WiFi，并确认校园认证和资费查询仍只走 WiFi。

公开页面与模拟返回的检查不代表真实课表导入成功。上述真实校园验证仍待完成，遇到无法识别的返回时会停止导入并保留旧课表。
