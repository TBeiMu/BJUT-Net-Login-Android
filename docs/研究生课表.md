# 研究生课表

工小助 v0.4.8 正式版支持北京工业大学研究生整学期课表。用户已确认主要功能可用，课表绑定与校园网账号相互独立。

## 一次登录，导入整个学期

1. 使用可上网的 WiFi 或移动数据，不需要先登录校园网。
2. 点击课表右上角导入图标，在学校统一身份认证页面输入学号、密码和需要的验证码。
3. 学校确认身份后，App 自动逐周读取整个学期，显示总体进度，无需逐周选择或确认。
4. 导入完成后返回原生课表，打开 App、翻周和查看详情均可离线使用。

v0.5.1 支持后台导入，v0.5.0 及以前仍需保持前台。提交学校登录后，切换 App、锁屏和返回时继续同一次导入，不重新提交密码。通知仅显示导入进度和“暂停导入”，点击通知返回课表，结束后自动移除；拒绝通知权限不阻塞导入。尚未提交的学校登录表单在离开前台时关闭，不在后台等待用户输入。

网络断开或实体网络切换、手动暂停、从最近任务划掉 App、服务被系统停止或运行达到 30 分钟上限时暂停并清除登录会话，保留已解析进度；返回后手动继续，重新登录并核对同一学号和学期。进程被系统回收后不自动恢复会话或重试密码。刷新期间保留原完整课表，所有周次获取成功后一次替换。

导入任务由独立的 `dataSync` 前台服务承接，运行时与课表网络监听不依赖 Activity / ViewModel。学校 Cookie 只在本次任务内存中使用，后台期间继续绑定原实体网络；结束、失败或暂停后清理。不会常驻、定时保活或开机恢复，也不会修改校园认证及资费查询的生命周期。验证结果见 [后台导入专项记录](testing/课表后台导入验证.md)。

“取消本次导入”需确认，仅删除未完成进度，保留完整课表和绑定信息。“更换 / 解绑课表账号”会清除课表及进度，校园网账号和设置保留。

当前源码中的姓名补全功能尚未发布对应 APK。在学校确认课表学号、保存绑定身份后，将姓名填入同学号校园网账号的默认备注；不必等整个学期导完。自定义备注保留，默认校园网账号和课表绑定保持独立。以后新增相同学号的账号也可直接使用本机已保存姓名，无需额外登录。验证边界见 [账号姓名补全验证](testing/账号姓名补全验证.md)。

## 课表操作

- 默认首页为课表“今日”时间线，可切换到整周；整周每页完整显示 12 节，有更晚课程时保留全部节次。
- 向上划下一周，向下划上一周；星期与左侧节次、时间固定，日期和课程参与动画。
- 连续轻划一划一周，下一次手势可立即接上。松手确定目标后周次标题立即更新，短拖回弹不改变周次；切页、后台与旋转保留已确定的周次。
- 点击周次标题、右上角按钮或右侧圆点可展开周次列表；周数来自学校数据。
- 浏览其他周时，“回到本周”位于圆点下方、贴齐右侧，以模糊半透明胶囊从右边滑入；展开列表时收起。
- 点击课程块查看课程名、地点、教师、日期和节次；重叠课程显示完整列表。
- “我的 → 课表管理”查看学期、更新时间、绑定与导入操作。

当前源码的右上角改为“＋”，点击后先选择“导入研究生课表”，再进入原学校登录流程；“导入本科生课表”暂未开放，不发出请求。“添加自定义课程”打开与课程详情同风格的编辑弹窗。尚未导入时，填写第一周周一和学期周数（默认 20，范围 1–60）即可离线建立课表。

课程名必填，教室、教师可选；按星期、周次及第 1–20 节区间安排，周次可多选或全选。学校和自定义课程详情都可编辑、删除，默认仅点击的本次，也可选择同一课程同一星期节次的其他周次；编辑分开选择原安排范围与调整后的安排，支持跨周调课。原非连续节次在未修改区间时保留。重叠课程仍分别展示，不互相覆盖。

完整刷新成功后，学校课程的个人编辑和删除被学校新数据替换；刷新失败、暂停或取消保留原内容。自定义课程独立保存，首次导入时按学校周次对齐，学校周数之外的安排不删除，在课表管理中提示调整。新学期及换账号不搬移旧记录；普通解绑保留自定义课程，损坏缓存清除仍须确认。旧本地学期可在“我的 → 课表管理”查看、添加、编辑和删除课程。

这批新增功能仅在源码中实现，尚未发布对应 APK，验证情况见 [课程添加与编辑验证](testing/课程添加与编辑验证.md)。

本周与当天标记按上海时区计算，返回前台、日期变化及点击“回到本周”时重新读取日期，不会触发重新导入。

2026 年 11 月 13 日的源码维护修复“今日”跨天选择：默认随当天日期更新，手动选择其他日期后保留浏览位置，选回今天后恢复跟随。状态恢复也保留该选择。此批改动尚未发布 APK，公开 v0.5.1 APK 仍使用原行为。

## 网络与数据保护

学校入口为 [研究生课表](https://itsapp.bjut.edu.cn/site/graduateSchedule/index)，学期及周视图接口为 `/yjskb/wap/default/get-index`、`/yjskb/wap/default/get-datatmp`。学号、学期、周数及课程字段来自学校返回，不用内部 uid 或用户输入代替已确认身份。

课表优先可上网的 WiFi，也支持移动数据；DNS 与 HTTP 绑定同一实体网络，排除 VPN。请求切网后停止，不自动重发密码。学校页面由原生会话传输、WebView 渲染，保留 TLS 校验，禁用 WebView 独立联网和持久化存储。

维护代码将 CAS 密码请求体标记为不可重放，阻止 HTTP 503／Retry-After: 0 引发的隐式重复提交。关闭会话时取消并等待 HTTP、DNS 与登录页资源清理，清理完成后才允许新导入或删除未完成进度。专项结果与公开版本边界见 [课表审查修复验证](testing/课表审查修复验证.md)。

完整课表与导入进度使用独立 Android Keystore／AES-GCM 加密，排除备份；不保存统一认证密码、Cookie、验证码或原始页面。存储损坏时提示处理，不静默覆盖。壁纸通过系统照片选择器导入、压缩重编码后保存，可恢复默认。

## 正式版与验证

用户已确认学校登录及整学期导入成功，并确认 v0.4.8 主要功能齐全可用。自动化检查覆盖解析、离线切周、空周、重叠课、进度继续、日期更新和账号隔离；模拟器检查包含实际页面绘制、小屏与放大字体。

校园认证是独立流程，只走 WiFi。课表左上角等待超过 3 秒时显示“登录超时”约 1 秒后恢复周次，认证仍继续，后续成功提示约 2 秒；完整结果在校园网连接页查看。

新设备、学校接口变化和特殊学期仍按实际反馈维护，不把模拟返回当作这些场景的校园验证。历史记录见 [v0.4.8 更新说明](releases/v0.4.8.md)。
