# 工小助 v0.5.4

- 修复校园网已经确认在线，却因另一端请求取消清理较慢而先显示“登录超时”、随后才显示“校园网已连接”的问题。公共或宿舍任一端确认在线后立即显示成功，不再等待另一端清理。
- 成功提示结束后恢复课表标题，清理完成时不重复播放；同任务迟到进度、清理异常或认证期限不会改写已确认的成功。
- 清理完成前保留原认证任务，防止重复登录；手动取消、切换 WiFi 或账号失效时仍丢弃旧结果。确实超过 3.5 秒尚未确认在线时，保留原短暂超时提醒。

版本 0.5.4／versionCode 35，包含已审查通过的 `9654774` 修复，沿用固定正式签名，可直接覆盖 v0.5.3 及此前正式版，保留账号、课表、自定义课程、壁纸和设置。请勿先卸载或清除数据；小鸟图标、开屏与加载动画保持原样。

验证：Debug 377 项、Release 371 项单元测试、两种 Lint 及固定签名构建通过；Android 12／16 各 18 项认证与标题回归通过，正式包覆盖 v0.5.3 后资料保留。详见 [v0.5.4 验证记录](../testing/v0.5.4验证.md)与[认证成功与请求清理分离验证](../testing/认证成功与请求清理分离验证.md)。检查使用虚构资料，本轮未重新使用真实校园账号验证联网，其他手机与校园网络以实际使用反馈为准。
