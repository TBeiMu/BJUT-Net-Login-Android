# 工小助 v0.5.3

- 自定义课程的星期支持多选，可将同一安排添加到多个星期；编辑和删除仍只影响选定范围，其他星期保留，重复目标去重。
- 修复多日调课合并超过单条保存容量后无法保存的问题。超限时分开保存调整后的安排，保留原范围外的课程；保存失败保留原课表。
- 课程详情去掉外层“课程详情”标题与容器，仅显示课程卡片；编辑、删除和关闭同排，关闭靠右，重叠课程仍可逐门查看和操作。
- “我的”顶部优先显示默认账号备注，无备注时显示完整学号／账号；副标题改为八个时段的暖心文案，每个时段三句按天轮换，移除原学号胶囊底色。
- 公共或宿舍端点确认已认证后立即显示“校园网已连接”，取消另一端探测，避免被另一端的超时拖延。尚未确认在线时仍先识别网络类型，再提交选定账号。
- 按当前宿舍网络流程移除旧二次认证请求、解析与提示。已认证状态直接完成；状态滞后时保留当前 WiFi 的实际联网复核，避免重复登录。

版本 0.5.3／versionCode 34，包含截至 `c9e194d` 的维护，沿用固定正式签名，可直接覆盖 v0.5.2 及此前正式版，保留账号、课表、自定义课程、壁纸和设置。请勿先卸载或清除数据；保留原小鸟图标、开屏与加载动画。

验证：Debug 367 项、Release 361 项单元测试、两种 Lint 及固定签名构建通过；Android 12／16 正式包覆盖 v0.5.2 后资料保留，多选课程保存、详情与个人页实际界面检查通过。详见 [v0.5.3 验证记录](../testing/v0.5.3验证.md)。宿舍无需二次认证依据用户当前使用说明；本轮未重新使用真实校园账号做联网验收，其他手机品牌以实际使用反馈为准。
