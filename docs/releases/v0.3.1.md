# 工小助 v0.3.1

- 修复 DNS 解析未返回时取消更新卡在“正在清理更新文件”的问题。更新解析绑定当前 WiFi，支持取消与超时，迟到结果不再触发请求。
- 修复账号文件损坏或密钥不可用时无法进入更新页的问题。设置页仍可检查更新和打开发布页，不会因此清除账号数据；不可用的账号设置暂时隐藏。
- 修复只检查新版、尚未下载时，重启 App 却显示“上次下载已暂停”的问题。区分发现新版与已开始下载，并兼容 v0.3.0 的旧更新记录。

versionCode 为 13，沿用固定正式签名。v0.3.0 用户可在“设置 → 检查更新”中更新，也可手动覆盖安装；请勿先卸载。账号、默认账号和设置会保留。

校园手机上的 WiFi 与移动数据同时开启行为、资费查询和设备注销仍待用户实测。模拟器验证不代替校园实机验收。

验证：Debug／Release 各 164 项单元测试、两种构建的 Lint 与正式签名 APK 构建通过；Android 12／16 各 25 项设备测试通过。回归用例覆盖 DNS 取消、超时与迟到回调、切网期间停止请求、旧更新记录迁移，以及存储异常时保留更新入口和原账号文件。

正式签名包已在模拟器中通过真实 GitHub 更新接口查询；模拟损坏账号文件后仍可检查更新，原文件未被自动清除。
