# 工小助 v0.3.2

- 支持通过移动数据手动检查更新，优先使用可上网的 WiFi。
- 使用移动数据下载 APK 前显示版本与安装包大小，点击“同意并下载”才开始；取消会保留已有下载进度。
- 授权仅对本次下载有效。网络切换、重试或重启后不能复用旧授权，流量重试需再次同意。
- WiFi 断开后先暂停，不会自动切换到流量下载；确认后的下载仍可在后台继续。
- 校园网登录、资费查询及其 DNS 仍只通过 WiFi，不受应用更新网络选择影响。

versionCode 为 14，沿用固定正式签名，可覆盖安装并保留账号。v0.3.0 及以上可通过“设置 → 检查更新”升级。首次获得流量更新能力前，请先使用 WiFi 或浏览器安装本版。

真实手机的运营商网络与校园网实测仍待用户确认；模拟器的移动网络验证不代表真实手机流量计费验收。

验证：Debug／Release 各 176 项单元测试、Lint 与正式签名构建通过；Android 12／16 各 28 项设备测试通过。在关闭 WiFi 的模拟器中，使用虚构版本清单验证取消后不下载、同意后才经移动网络下载、重试再次询问；实际 APK 的版本不匹配被正常拦截，账号文件保持不变。
