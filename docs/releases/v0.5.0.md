# v0.5.0（versionCode 31）

全新界面与标志。功能、账号、课表数据和校园网认证方式不变。

- 课表默认显示“今日”：今天的课按时间排成一条时间线，正在上的课显示进度和剩余时间，课间写明空闲时长，末尾预告明天的课；上方七天条可点选或左右滑动切换日期。右下角“整周”切到原来的整周网格，选择会被记住。
- 整周网格保留 v0.4.12 的跟手翻页、连续轻划与周次即时反馈，新增“此刻线”标出当前时间、正在上的课随时间填满、已上完的课变灰；课程名均匀断行，不再单字掉行。
- 全新视觉：纸白底色、实心白色卡片、中性墨色文字与朱红点缀；资费、我的、外观设置及各二级页统一改版，深色模式改为中性炭灰。六种背景保留，改为同色系的淡雅底色。
- 底栏改为白色胶囊，选中项下方有滑动的红点。
- 全新标志：三块课程卡拼成的“工”字，朱红竖笔代表“此刻”。桌面图标支持安卓 13 主题图标；开屏动画是一张周课表凝成“工”字。
- 加载动画改用标志：登录校园网时 WiFi 信号拉直变成“工”，其他等待时“此刻”在上下两横之间弹跳。
- 页面切换、卡片入场、资费数字滚动、按压回弹等动效；系统关闭动画时自动停用装饰性动效。

沿用固定正式签名，覆盖安装保留账号、默认账号、课表、壁纸及设置；请直接覆盖安装，不要卸载。

本版基于 v0.4.12 合入新版界面，versionCode 31 高于此前所有正式版和测试包，可直接覆盖更新。

验证：合并后 Debug／Release 各 284 项单元测试与两种 Lint 通过，Debug／Release 构建及设备测试编译通过；另以按需运行的界面截图与动画录制检查，在电脑上用真实代码和虚构资料逐帧渲染界面与动画，包括浅色、深色、360dp 小屏和空数据状态。本版未在模拟器或真机上执行设备测试，开屏矢量动画的中间过程、不同手机桌面对图标的显示仍需实际使用确认。
