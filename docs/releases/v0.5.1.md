# 工小助 v0.5.1

- 桌面 Logo 换成用户提供的蓝色小鸟，保留原图蓝色、青色与黄色细节；关于页同步使用新图，主题图标和通知图标使用同一轮廓的单色版本。
- 按用户要求保留原来的开屏“工”字动画和加载标志，包括“信号变成工”和“此刻弹跳”。
- 学校登录提交后可切换 App 或锁屏继续导入课表，返回复用同一任务；断网、换网、主动暂停或从最近任务划掉时保留进度，手动继续。完成后自动结束服务和通知，不后台常驻。
- 固定课表右下角“今日／整周”按钮及左上角小字、标题区的位置，切换视图或校园网提示时不再上下移动。
- 修复“我的 → 检查更新”加载结束后的箭头漂移，保留检查期间的重复点击拦截。
- 合入仓库最新整周排版：左侧开始时间—节次—结束时间，课程文字上下左右居中，去除课程卡左侧色条。

基于发布前核对的 GitHub 主分支最新代码 `25e8b84`。版本为 0.5.1／versionCode 32，沿用固定正式签名，可直接覆盖 v0.5.0 及此前正式版本，保留账号、默认账号、课表、壁纸和设置；不要先卸载或清除资料。

验证：Debug／Release 各 295 项单元测试、两种 Lint 与固定签名 APK 构建通过；Android 16 完成 33 项新图标及相关界面检查，v0.5.0 覆盖升级核对账号、课表、壁纸与设置保留。原开屏与加载文件保持一致；本次未完成 Android 12／14 或真实手机专项检查。具体结果记录在 [v0.5.1 验证记录](../testing/v0.5.1验证.md)。历史校园功能已获用户确认；新增图标在不同手机桌面上的裁切、主题显示及后台省电策略仍按实际使用反馈确认，不把虚构课程和网络测试当作真实校园验收。
