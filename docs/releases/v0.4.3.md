# v0.4.3（versionCode 19）

- 更正课表翻周方向：向上划进入下一周，向下划返回上一周；仍然一屏显示 12 节，不增加页内滚动。
- 校园网提示改到左上角“第几周”的同一标题位置。真实认证进行中显示“正在登录校园网”，成功或确认已联网后显示“校园网已连接”约 2 秒，然后恢复当前所选周次。
- 统一标题提示的状态与计时，避免快速登录或界面状态更新顺序导致提示提前消失。后台完成后回到课表才展示未显示过的结果，旋转和切换页面不会重复播放。
- 失败、取消或切网时恢复周次，不误报联网成功；完整认证结果仍可在“我的 → 校园网连接”查看。课表导入、资费登录不会触发校园网成功提示。
- 课表导入暂停或失败后，增加“取消本次导入”。课表状态提示和课表管理页均可操作，确认后清除本次未完成进度并收起重试提示，保留已有完整课表、绑定账号及校园网账号。

沿用固定正式签名，支持覆盖安装，保留账号、课表和设置。本次不改变校园网认证请求及课表存储格式。

验证：Debug／Release 各 227 项单元测试、两种 Lint 和 APK 构建通过。Android 12／16 各执行 65 项完整设备回归，分别通过 63／64 项，另有 2／1 项因通知权限前提不适用而跳过；Android 14 的 16 项相关回归全部通过。涵盖上下划方向、快速登录、后台返回、提示消失与去重、取消导入确认、保存失败保护、迟到响应丢弃和旧课表保留。

已检查实际标题截图，并在启用混淆的固定签名 Release APK 中通过隔离的虚构状态验证“登录中 → 已连接 → 周次”的显示。v0.4.2 → v0.4.3 覆盖安装后，虚构账号、默认账号、设置及完整课表可读取，加密文件字节不变。

手机实际认证与提示时机仍需用户复测；模拟认证和界面测试不等同于真实校园联网验收。
