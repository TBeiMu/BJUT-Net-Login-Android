# v0.4.2（versionCode 18）

- 课表改为矿小助风格的紧凑周视图：周次标题、今日日期高亮、居中彩色课程块、右侧周次指示与课程分布缩略图。
- 每页完整显示 12 节，向下划下一周、向上划上一周，无页内滚动。保留晚间课程，跨页和旋转保留选中周次。
- 正常查看时隐藏课表网络和导入完成说明；仅在导入、暂停或失败时显示紧凑提示。校园网认证成功后，顶部短暂显示“校园网已连接”，同一次任务不重复弹出。
- “我的”精简为个人信息与六个入口：课表管理、校园网账号、校园网连接、外观设置、应用更新、关于工小助。详细操作进入二级页，仍保留底部导航。
- 资费账号管理和认证／更新通知可直达对应页面。延续原有账号加密、校园认证、资费、WiFi／移动数据课表导入和应用更新功能。

采用固定正式签名，可直接覆盖安装并保留账号、课表和设置。

验证：Debug／Release 各 219 项单元测试、两种 Lint 和 APK 构建通过。Android 12／14／16 各执行 59 项设备回归，分别通过 57／58／58 项，另有 2／1／1 项因通知权限前提不适用而跳过。已检查浅色、深色、自定义壁纸、放大字体和小屏下的 12 节完整显示。

隔离模拟器已验证 v0.4.1 → v0.4.2 覆盖安装：校园网账号、默认账号、设置及完整课表均可读取，加密文件字节不变。手势、二级页返回、周次恢复、认证短提示去重及通知目标页面已有自动化回归。

实测状态：用户已确认 v0.4.1 登录页恢复显示、课表导入成功。本次主要调整界面；其他设备、多个周次课程一致性及全部校园认证场景仍需继续核对，模拟测试不代替这些验收。
