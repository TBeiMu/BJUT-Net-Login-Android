# v0.4.12（versionCode 30）

- 优化课表连续轻划：保持一划一周，下一次手势立即接管当前画面，不必等待上一次动画结束；连续多次快划不会因翻页边界重置而突然跳动。
- 松手确定目标后，左上角周次、右侧圆点及今日标记立即更新，减少周次反馈延迟。短拖仍回弹，长拖或快划仍最多翻一周，首末周不循环。
- 缩短吸附过程，快划约 150ms、慢拖约 200ms；日期和课程共用进度，星期、节次和时间栏保持固定。动画逐帧位移交给图形层，减少课程内容重组。
- 后台、切页、旋转、弹窗或课表替换会结束旧交互，保留已松手确定的周次；未松手拖动不保存，迟到动画不能覆盖新选择。

沿用固定正式签名，可直接覆盖 v0.4.11，保留账号、默认账号、课表、壁纸和设置。v0.4.9 及以后可通过 App 内检查更新；v0.4.8 及以前仍需手动下载并覆盖安装一次，请勿卸载。

验证：Debug／Release 各 284 项单元测试、两种 Lint 与固定签名构建通过。Android 12／14／16 模拟器各 38 项相关检查通过，覆盖连续六次前翻和六次回翻、松手下一帧周次反馈、日期同步、固定栏节点、取消与恢复、课表详情、本周按钮及校园网标题。测试夹具的后台恢复和冻结时钟处理修正后已复跑受影响场景；Android 16 恢复模拟器 WiFi 后完成依赖 WiFi 的标题回归。

Android 12 最终签名包通过 v0.4.11 → v0.4.12 覆盖安装、资料解密及文件摘要核对；分段原生触摸确认跟手位移、短拖回弹、长拖翻周和连续快划不丢周。检查浅色、深色、小屏、大字体与动画中间画面。所有测试资料均为虚构数据；本轮手机实际手感仍需使用反馈，未新增校园网实测。详见 [专项验证记录](../testing/课表连续轻划验证.md)。
