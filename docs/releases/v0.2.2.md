工小助 v0.2.2：修复校园网已联网后无法登录查询资费，支持 Android 12 及以上。

- 兼容学校当前的同源 `/Self/login/?302=LI` 登录跳转，修正旧版因末尾斜杠和已知参数而提示“自助服务返回了不允许的跳转”的问题。
- “登录查询”继续使用首页选定的已保存账号建立独立资费网页登录会话，无需先在系统浏览器登录；浏览器与 App 的 Cookie 不共享。
- 仅接受已确认的登录路径和参数，跨站、HTTPS 降级、任意返回地址参数及重复标记仍会停止请求。密码通过固定学校 HTTPS 表单提交，失败后不自动重试。
- 沿用固定正式签名，versionCode 从 8 递增到 9，可直接覆盖安装并保留账号，请勿先卸载。

已只读确认学校未登录 dashboard 的实际 HTTP 302 跳转与随后返回的登录表单，未提交真实账号密码。用户反馈的旧版失败已定位并通过虚构响应回归测试；修正版资费查询仍待校园手机验证，真实设备下线仍待验收。宿舍认证修复沿用 v0.2.1。

验证结果：Debug／Release 各 119 项单元测试、两种构建的 Lint 与正式签名 APK 构建、12 项 Android 12 端检查通过。模拟器从 v0.2.1（versionCode 8）覆盖安装到 v0.2.2（9）成功，已有虚构账号与设置正常读取，签名与固定发布证书一致。

更新后先确认校园 WiFi 能上网，再打开“资费”点击“登录查询”；学校要求验证码时按提示输入。`SHA256SUMS.txt` 提供 APK 文件校验值。
