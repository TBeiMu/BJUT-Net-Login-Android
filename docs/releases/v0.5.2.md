# 工小助 v0.5.2

- 课表右上角改为“＋”，先选择研究生课表导入或添加自定义课程。本科生课表导入暂未开放。
- 支持离线建立本地学期，并按星期、周次、起止节次添加课程；课程名必填，教室和教师可选。无需先导入学校课表。
- 学校和自定义课程都可在详情中编辑、删除本次或指定周次，支持临时调课。完整刷新成功后，学校课程以新数据为准；自定义课程保留，首次导入按学校周次对齐，旧学期可在课表管理中继续查看。
- 首次添加校园网账号时，备注留空可使用本机同学号课表姓名，或在前台 WiFi 可用后尝试一次学校登录补全姓名。失败或需要验证码时保留账号，后续课表导入仍可补全；自定义备注不覆盖，历史账号不自动提交学校登录。
- 移除校园网账号页顶部重复的选择框，通过账号卡片设为默认、编辑或删除。
- 资费查询提示与加载动画紧邻显示在右上方，与账号文字字号一致；固定提示和卡片占位，查询时按钮不再上下移动。
- 修复学校登录异常响应导致的重复提交、课表取消后的请求清理，以及“今日”跨天默认日期更新。保留原小鸟图标、开屏和加载动画。

版本 0.5.2／versionCode 33，基于发布前已核对并通过 GitHub 检查的源码 `dd322da`。沿用固定正式签名，可直接覆盖 v0.5.1 及此前正式版，保留账号、课表、壁纸和设置；请勿先卸载或清除数据。

验证：Debug 358 项、Release 352 项单元测试、两种 Lint 及固定签名构建通过；Android 12／16 独立界面组各 24 项通过，后台导入适用检查通过（Android 12 的 1 项系统超时用例不适用）。Android 16 正式签名包覆盖 v0.5.1 后账号、学校课表、壁纸和设置保留，正式包课程添加及重启读取通过。混合测试进程的通知用例隔离限制已记录。真实账号首次自动 CAS 登录仍未完成完整验收，其他手机品牌和真实校园网络以实际使用反馈为准。专项及发布核验见 [v0.5.2 验证记录](../testing/v0.5.2验证.md)。
