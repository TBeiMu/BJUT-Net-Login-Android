# 工小助 v0.3.0

- 设置页新增“检查更新”，手动获取版本号、中文更新说明和 APK 大小。
- 支持在 App 内下载新版 APK，离开 App 后继续下载；始终只使用实体 WiFi。
- WiFi 断开或切换时暂停，保留已下载内容；回到 App 点击“继续下载”后恢复。
- 下载完成后校验文件 SHA-256、包名、版本、系统要求和固定正式签名，安装前再次检查。
- 点击“安装更新”后由系统确认覆盖安装，保留本机账号、默认账号和设置。首次使用需允许工小助“安装未知应用”。
- GitHub Releases 新增机器可读的 update.json，与 APK、校验文件一同发布。

本版本的 versionCode 为 12，沿用固定正式签名。v0.2.4 及以前需要先从发布页手动覆盖安装本版；后续版本可使用 App 内更新。请勿先卸载。

仅在用户手动操作时检查或下载，不包含自动检查、强制更新或动态代码热补丁。拒绝通知权限仍可下载，回到设置页查看进度。下载中断、设备重启或被系统停止后，需要手动继续。

校园手机上的 WiFi 与移动数据同时开启行为、资费查询和设备注销仍待用户实测。模拟器验证不代替校园实机验收。

开发验证：Debug／Release 各 157 项单元测试、两种构建的 Lint 与正式签名 APK 构建通过；Android 12／16 各 21 项设备测试通过。隔离环境验证后台下载、WiFi 断开暂停及手动续传、进程重建、通知拒绝、安装权限拒绝与安装取消、错误签名／包名／版本拦截，以及系统确认覆盖安装后账号保留。
