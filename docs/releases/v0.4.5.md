# v0.4.5（versionCode 21）

- 修复课表左上角在“登录超时”和“校园网登录失败”之间闪回周次：超过 1.5 秒仍未完成时持续显示“登录超时”，任务失败后直接显示“校园网登录失败”，约 2 秒后恢复“第 X 周”。后续成功会直接显示“校园网已连接”；任务最终超时也显示失败。
- 超时提示属于本次任务的等待状态，旋转、切页及进度变化不会重新计时；取消、切网或新任务仍丢弃旧提示。认证请求及 75 秒任务上限保持不变。
- 资费页在线设备在登录时间、在线时长下面增加“使用流量”，按学校网页算法显示 MB 和三位小数。缺失或异常字段显示“未获取”，同会话重复行不累计。
- 资费卡片与“我的”统一为半透明小圆角样式，删除查询诊断入口、正常查询完成说明和多余文字，保留验证码、查询时间及必要错误提示。
- “我的”删除头像，将“应用更新”改为“检查更新”：平时点击直接查询版本，有新版使用三按钮弹窗，最新时只提示“已是最新，无需更新”。检查结果不会因旋转重复播放；失败提示保留发布页入口。
- 有下载、暂停或待安装任务时仍可进入更新管理。更新弹窗避开在线设备选择框；移动数据下载仍需本次同意，设备注销仍需确认。

沿用固定正式签名，可覆盖安装 v0.4.4，保留账号、默认账号、课表和设置，请勿先卸载。本次不修改校园认证请求、课表导入协议或加密存储格式。

验证：Debug／Release 各 256 项单元测试通过，Lint 均无问题，两种 APK 构建完成。Android 12／14／16 隔离模拟器各 39 项相关检查通过，覆盖慢认证持续提示、失败后恢复周次、旋转、后台结果、新版与最新提示、下载恢复、资费设备流量、账号操作和取消导入。

已核对小屏、浅色、深色及放大字体的实际绘制。固定签名 v0.4.4 → v0.4.5 覆盖安装后，虚构账号、默认账号、设置和完整课表保留，原有加密文件摘要不变；另外在最终签名包中验证“超时持续显示 → 失败 → 周次”，中间不出现周次。测试传输与混淆符号仅在隔离测试中使用，正式包没有测试或校验绕过入口。

用户已确认 v0.4.1 学校登录页显示与整学期导入成功。标题衔接、新资费流量数值、真实新版下载及手机双网络行为仍需实机核对；模拟认证和虚构数据不代表校园联网或查询验收。
