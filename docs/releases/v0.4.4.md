# v0.4.4（versionCode 20）

- 精简“我的”首页：圆形头像、姓名与脱敏学号、两组半透明卡片；六个入口只保留图标、名称和箭头，删除多余说明。完整功能继续在二级页使用。
- 课表导入／刷新按钮移至右上角周次选择按钮左侧。换周时固定星期和左侧节次栏，只切换日期与课程卡片。
- 补充用户提供的北工大 1–12 节上课时间，按节次、开始、结束三行展示；保留晚间课程，未知节次不编造时间。
- 增加启动检查和三按钮更新弹窗，按钮从左到右为“取消更新／忽略本次更新／立即更新”。“我的 → 应用更新 → 检查更新”使用同一弹窗；忽略只屏蔽当前版本的自动提示，下一版仍可提醒。
- 更新弹窗沿用矿小助参考风格。修复忽略版本记录损坏后自动提醒失效，以及横屏大字体更新说明区域不足一行的问题；空间不足时标题和说明整体滚动，按钮固定。
- 下载由用户选择后启动；流量下载仍需单独取得本次同意，拒绝通知权限也能继续下载。取消或忽略新版提示保留旧下载进度。
- 校园网标题超过 1.5 秒仍未完成时显示“登录超时”，实际失败显示“校园网登录失败”，成功显示“校园网已连接”，各约 2 秒后恢复周次。1.5 秒仅控制标题提示，后台认证继续执行，后续成功仍能显示连接结果。
- 修复取消导入确认框提前消耗校园网成功提示；更新提示避开学校登录页、课表详情与其他确认框。

沿用固定正式签名，可直接覆盖安装 v0.4.3，保留账号、默认账号、课表及设置，请勿先卸载。本次不改变校园认证请求、课表登录流程或加密账号与课表格式。

验证：Debug／Release 各 247 项单元测试、两种 Lint 和签名 APK 构建通过。Android 12／14／16 隔离模拟器各执行 43 项相关检查，Android 12 通过 42 项、1 项通知权限测试因系统版本不适用跳过；Android 14／16 全部通过。覆盖两处 review 修复、启动与手动检查、忽略版本、通知拒绝、流量下载同意与拒绝、确认框避让、课表动画与时间栏、“我的”二级导航和账号管理。

已核对浅色、深色、大字体及横屏实际绘制；固定签名 v0.4.3 → v0.4.4 覆盖安装后，虚构账号、默认账号、设置和完整课表可读取，加密文件字节保持不变。测试传输与数据仅存在于测试代码，正式包没有校验绕过入口。

用户此前已确认 v0.4.1 学校登录页恢复显示并成功导入课表。新界面、短提示、真实新版下载及手机双网络行为仍需实机核对；模拟认证和虚构测试数据不代表校园联网或查询验收。
