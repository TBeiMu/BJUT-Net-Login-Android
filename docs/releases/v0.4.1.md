# v0.4.1（versionCode 17）

- 修复课表登录页仅显示“学校统一身份认证”等顶部文字、网页区域持续白屏的问题。网页控件现在使用明确的原生布局参数，学校内嵌登录框可取得完整显示高度。
- 新增登录页可见性回归：核对内嵌页面高度、输入框位置和实际绘制，覆盖加载提示变化后的重新布局；不再仅凭 DOM 元素存在判断页面显示成功。
- 支持从 v0.4.0（含测试包）通过 App 内更新或手动下载覆盖安装，保留账号和设置。

课表支持普通 WiFi 与移动数据，一次学校登录后自动获取整学期；导入时需要保持前台，切网或离开前台后暂停并保留进度。校园网认证和资费查询继续仅走 WiFi。

验证：Debug／Release 各 215 项单元测试、两种 Lint 和 APK 构建通过。Android 12／16 的登录页布局、网页提交和模拟整学期导入回归各 3 项通过。使用启用混淆和固定正式签名的 Release APK，验证了 Android 12 的学校页面显示，以及 Android 16 在 WiFi、仅移动数据下的真实登录框高度和实际绘制。v0.4.0 → v0.4.1 覆盖安装后，虚构账号可读取，账号与设置文件字节不变。

**真实账号验证仍待完成。** 公开登录页的加载和绘制验证未提交真实密码，不能代替整学期课程内容核对；小米 13／Android 16 的修复效果仍需用户复测。
