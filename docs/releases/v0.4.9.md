# v0.4.9（versionCode 25）

- 修复仓库从 `BJUT-Net-Login-Android` 改名为 `BJUT_gxz` 后，App 内检查更新显示“更新地址不受信任”的问题。新版使用 `TBeiMu/BJUT_gxz` 的版本源、APK 和发布页地址。
- 仅兼容两个已知仓库名之间的迁移跳转；固定 APK 的版本标签和文件名不能变化。跨站、其他仓库、降级 HTTP 和异常参数仍拒绝，大小、SHA-256、包名、版本和固定签名校验保留。
- 查询与下载继续使用独立绑定的实体网络，不携带校园账号或 Cookie。移动数据下载仍需本次同意，断网和换网后手动继续。

**v0.4.8 及以前版本请从新仓库手动下载本版 APK 并覆盖安装一次，不要卸载。**旧 APK 无法通过已被拦截的更新请求自行修复；安装本版后恢复 App 内检查与后续更新。原有账号、默认账号、课表和设置保留，历史 APK 和标签不替换。

本次只修复更新地址，校园认证、资费查询和课表功能沿用已正式可用的 v0.4.8。

验证：Debug／Release 各 261 项单元测试、两种 Lint 和签名构建通过，覆盖新旧仓库跳转、固定版本限制、非法地址、无凭据请求及 Range 续传。Android 12／14／16 隔离模拟器各 23 项更新相关检查通过，包含通过绑定实体网络实际读取新仓库公开版本文件、更新弹窗、流量授权、下载恢复及账号存储异常。

最终正式签名包在 Android 12 实际点击“检查更新”，成功显示“已是最新，无需更新”，没有不受信任错误。固定签名 v0.4.8 → v0.4.9 覆盖安装后，虚构账号、默认账号、设置和完整课表保留，原加密文件摘要不变。公开网络检查只读取版本信息，不使用校园凭据；其他自动化场景使用虚构数据。
