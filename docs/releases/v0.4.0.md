# v0.4.0（versionCode 16）

- 底部导航改为“课表／资费／我的”，默认打开课表。校园网账号、联网操作、设置和应用更新集中到“我的”。
- 增加研究生原生周课表：用户登录一次后自动导入整个学期，无需逐周操作；支持离线查看、左右翻周、选择周次、返回本周及重叠课程详情。
- 课表账号独立绑定；通过学校 CAS 页面手动登录，不保存密码。课表登录、整学期导入和刷新支持普通 WiFi 与移动数据，无需先连接校园网；优先使用可上网的 WiFi，DNS 与请求绑定同一个选定网络。
- 课表断网或切换 WiFi／移动数据后暂停，清除临时登录会话并保留导入进度；手动继续时重新登录。校园网认证和资费查询继续仅走 WiFi，流量下载 APK 仍须本次确认。
- 整学期和未完成进度独立加密保存。离开前台或切网暂停，重新登录后继续；刷新完成前保留旧课表。
- 增加蓝青渐变背景、半透明卡片和彩色课程块，可通过系统照片选择器更换壁纸，并适配深色模式。
- 保留校园网自动认证、短时后台认证、资费查询、设备注销和应用内更新。固定签名覆盖安装保留校园网账号和设置。
- 修复课表请求超时后未清理登录会话、未显示失败提示的问题；保留旧课表和导入进度，等待用户手动重试，不自动重发凭据。
- 修复跨周返回 App 后“本周”仍指向旧周次的问题；返回前台、日期变化和点击时更新日期及当天标记。

验证：Debug／Release 各 215 项单元测试、两种构建的 Lint 和 APK 构建通过。Android 12／14／16 各执行 52 项设备回归：Android 12／16 各 50 项通过、2 项通知权限前提不适用而跳过；Android 14 为 51 项通过、1 项跳过。覆盖课表、账号管理、校园认证、资费及应用更新。

已分别验证 WiFi 与移动数据下的学校公开登录页。Android 12／14／16 关闭 WiFi 后，移动数据专项各 7 项全部通过，包含真实学校页面加载、网络隔离和虚构课表导入，未提交真实凭据。单元测试确认一次登录自动获取全部 20 周，及超时、切网后保留进度和清除会话。学校移动端所需的本地存储访问由仅当前页面有效的内存对象兼容，WebView 持久化存储继续关闭。

隔离模拟器已验证 v0.3.3 → v0.4.0 覆盖安装，账号、默认账号和设置的加密文件字节不变，账号可正常读取。

若已安装此前的 v0.4.0 测试包，请手动下载本次 APK 覆盖安装；同为 versionCode 16，App 内检查更新不会提示升级。

**校园验证状态：待验证。** 真实校园账号登录后的接口返回、多个周次课程一致性、验证码实测及手机双网络切换仍待验收。模拟页面、虚构数据和公开登录页加载均不能代替真实课表导入验收。校园核对步骤见 docs/研究生课表.md。
