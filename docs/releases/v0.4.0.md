# v0.4.0（versionCode 16，测试候选）

- 底部导航改为“课表／资费／我的”，默认打开课表。校园网账号、联网操作、设置和应用更新集中到“我的”。
- 增加研究生原生周课表：整学期导入、离线查看、左右翻周、选择周次、返回本周及重叠课程详情。
- 课表账号独立绑定；通过学校 CAS 页面手动登录，不保存密码。所有课表请求由当前实体 WiFi 的独立会话发送。
- 整学期和未完成进度独立加密保存。离开前台或切网暂停，重新登录后继续；刷新完成前保留旧课表。
- 增加蓝青渐变背景、半透明卡片和彩色课程块，可通过系统照片选择器更换壁纸，并适配深色模式。
- 保留校园网自动认证、短时后台认证、资费查询、设备注销和应用内更新。固定签名覆盖安装保留校园网账号和设置。

验证：Debug／Release 各 207 项单元测试、两种构建的 Lint 和 APK 构建通过。Android 12 的 46 项常规设备用例中 45 项通过、1 项通知权限前提不适用而跳过；Android 16 的 46 项常规用例及通知设置恢复专项通过；Android 14 的全量回归及新增课表导入、资源加载、界面专项通过。已检查深色和放大字体，使用虚构课表生成界面预览。

已通过绑定 WiFi 的原生传输在模拟器加载学校真实公开登录页，中文账号／密码界面可显示，未提交真实凭据。学校移动端所需的本地存储访问由仅当前页面有效的内存对象兼容，WebView 持久化存储继续关闭。

隔离模拟器已验证 v0.3.3 → v0.4.0 覆盖安装，账号、默认账号和设置的加密文件字节不变，账号可正常读取。

**尚未发布 Release。** 真实校园账号登录后的接口返回、多个周次课程一致性、验证码实测及手机双网络切换仍待验收。模拟页面、虚构数据和公开登录页加载均不能代替真实课表导入验收。完成 docs/研究生课表.md 中的校园核对后再发布。
