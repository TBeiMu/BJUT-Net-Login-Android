工小助 v0.2.1：修正宿舍 WiFi 已联网却显示认证失败，支持 Android 12 及以上。

- 修正宿舍第一阶段认证已生效、网关状态仍返回未登录时，App 跳过实际联网检查并提示“认证已提交，状态未确认”的问题。
- 识别到有效宿舍服务后，在读取和提交密码前检查当前 WiFi 的 IPv4 外网。网关状态滞后、认证被拒绝或响应丢失后也会复核，避免重试重复登录。
- 确认已有网时显示“宿舍 WiFi 已联网（IPv4 已验证）”，按钮变为“检查联网状态”；只证明实际联网，不将未确认的认证阶段报告为完成。
- 首个 HTTPS 204 检测不可用时使用固定备用检测地址。均绑定同一实体 WiFi、仅使用 IPv4，不发送密码或 Cookie，不跟随跳转，保留 TLS 校验。
- 保留公共 WiFi 认证、资费和在线设备管理；沿用固定正式签名，versionCode 从 7 递增到 8，可覆盖安装并保留账号，请勿先卸载。

用户已确认在宿舍关闭移动数据仍能上网，但旧版状态提示不正确。本次修复通过虚构响应回归验证，尚待用户在宿舍手机复测，不能以模拟测试代替校园验收。资费查询和真实设备下线的验证状态沿用 v0.2.0，仍待校园手机验证。

验证结果：Debug／Release 各 114 项单元测试、两种构建的 Lint 与正式签名 APK 构建通过；12 项 Android 12 端检查通过。模拟器从 v0.2.0（versionCode 7）覆盖安装到 v0.2.1（8）成功，已有虚构账号及设置正常读取，签名与固定发布证书一致。

IPv4 检测主地址为 `https://connectivitycheck.platform.hicloud.com/generate_204`，备用地址为 `https://connect.rom.miui.com/generate_204`。检测未成功仍保留未确认提示，不等同于断网或密码错误。

下载 `gongxiaozhu.apk` 覆盖安装，`SHA256SUMS.txt` 提供文件校验值。宿舍复测时关闭移动数据，重新打开 App，核对提示与外网访问；已联网后再次点击应检查状态并继续显示已联网。
