# v0.3.3（versionCode 15）

- 认证开始后可切换 App、按 Home 或锁屏继续本次任务；划掉 App、取消或 WiFi 变化时停止。
- 静默通知仅展示认证进度和取消操作，任务结束即移除；结果只在首页显示。通知未授权仍可认证。
- 返回首页复用进行中的任务，后台完成后的首次返回只展示结果，不立即重复提交认证。
- 公共／宿舍识别与 IPv4 外网检查并行，去除宿舍第一阶段前不会使用的二次认证预检查；增加脱敏步骤耗时。
- 任务最长 75 秒，绑定当前实体 WiFi；不增加后台保活、定时登录或移动数据认证。
- 修复正常切后台被当成 WiFi 断开、导致上次资费数据消失的问题；保留显示数据并清除会话，返回后确认当前 WiFi 再查询。
- 通知权限被永久拒绝后可通过首页进入系统通知设置恢复；返回 App 自动刷新权限状态。

已完成：Debug／Release 各 189 项单元测试、两种构建的 Lint、Debug 与固定正式签名 APK 构建；Android 14／16 各 41 项常规设备测试和 1 项通知设置恢复专项测试通过，Android 12 为 40 项通过、1 项通知权限前提不适用而跳过。服务测试使用虚构认证，覆盖后台、旋转、锁屏、划掉、切网、通知取消、系统超时回调、旧启动请求和更新服务并行。Android 14／16 在启动测试前撤销通知权限，验证拒绝通知仍可认证。

本轮新增单元和设备回归覆盖暂停监听保留资费、真实断网清空旧数据、后台认证完成不影响资费，以及永久拒绝通知后进入设置恢复和返回刷新。Android 16 首次全量运行的既有账号切换测试等待超时，单独复测与全套重跑均通过；未改动该测试或账号切换实现。

此前隔离 Android 12 模拟器从正式 v0.3.2 覆盖安装 v0.3.3 后，虚构账号可读，账号、默认账号和设置所在加密文件字节不变。证书 SHA-256 与 `release-signing.sha256` 一致。

待验证：校园公共／宿舍真实认证耗时，认证后立即切换 App 或锁屏的真实联网结果，手机 WiFi 与移动数据同时开启，以及手机厂商后台限制。模拟测试不代表校园认证成功。

升级方式：v0.3.0 及以上可在“设置 → 检查更新”下载新版，或下载本页的 `gongxiaozhu.apk` 覆盖安装。沿用固定正式签名，保留账号和设置，请勿先卸载。附件同时提供 `SHA256SUMS.txt` 和 `update.json`。
