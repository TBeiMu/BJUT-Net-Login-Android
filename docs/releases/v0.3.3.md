# v0.3.3（versionCode 15，待发布）

- 认证开始后可切换 App、按 Home 或锁屏继续本次任务；划掉 App、取消或 WiFi 变化时停止。
- 静默通知仅展示认证进度和取消操作，任务结束即移除；结果只在首页显示。通知未授权仍可认证。
- 返回首页复用进行中的任务，后台完成后的首次返回只展示结果，不立即重复提交认证。
- 公共／宿舍识别与 IPv4 外网检查并行，去除宿舍第一阶段前不会使用的二次认证预检查；增加脱敏步骤耗时。
- 任务最长 75 秒，绑定当前实体 WiFi；不增加后台保活、定时登录或移动数据认证。

已完成：Debug／Release 各 186 项单元测试、两种构建的 Lint、Debug 与固定正式签名 APK 构建；Android 14／16 各 38 项设备测试通过，Android 12 为 37 项通过、1 项通知权限前提不适用而跳过。服务测试使用虚构认证，覆盖后台、旋转、锁屏、划掉、切网、通知取消、系统超时回调、旧启动请求和更新服务并行。Android 14／16 在启动测试前撤销通知权限，验证拒绝通知仍可认证。

隔离 Android 12 模拟器从正式 v0.3.2 覆盖安装 v0.3.3 后，虚构账号可读，账号、默认账号和设置所在加密文件字节不变。证书 SHA-256 与 `release-signing.sha256` 一致。

待验证：校园公共／宿舍真实认证耗时，认证后立即切换 App 或锁屏的真实联网结果，手机 WiFi 与移动数据同时开启，以及手机厂商后台限制。模拟测试不代表校园认证成功。本次安装包为本地交付，尚未创建 GitHub Release。
